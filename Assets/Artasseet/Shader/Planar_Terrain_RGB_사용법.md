# 평지 RGB 마스크 셰이더

`Planar_Terrain_RGB.mat`을 복제하여 평지 메시의 머티리얼로 사용합니다.
셰이더 목록의 경로는 `Tank/지형/Planar_Terrain_RGB`입니다.
기존 씬의 머티리얼은 자동 교체하지 않습니다.

## 텍스처 설정

- R: 기본 흙, G: 모래, B: 퇴적층입니다. 각 재질의 색상과 노멀을 넣습니다.
- 노멀 이미지는 Unity의 Texture Type을 Normal map으로 설정합니다.
- 마스크 이미지는 일반 텍스처로 가져오고 **sRGB를 끕니다**. 정확한 혼합이 필요하면 압축도 끕니다.
- 검정 마스크 또는 마스크 미지정은 기본 흙입니다. RGB 합이 0이 아니면 비율을 정규화합니다.
  예를 들어 노랑(1,1,0)은 흙과 모래를 반씩 섞고, 흰색은 세 재질을 같은 비율로 섞습니다.
- AO는 사용하지 않습니다. 매끄러움은 재질별 수치를 같은 마스크로 혼합합니다.

## 마스크 좌표

`마스크에 메시 UV0 사용`은 기본으로 켜져 있습니다.
섭스턴스 페인터에서 해당 메시의 UV에 맞춰 칠한 RGB 마스크를 그대로 넣습니다.
마스크를 개별 영역에 칠하려면 UV가 서로 겹치지 않아야 합니다.

여러 지형 조각에 큰 마스크 한 장을 사용할 때는 이 옵션을 끕니다.
`월드 마스크 시작 위치 (X,Z)`는 맵의 최소 X/Z 위치,
`월드 마스크 크기 (X,Z)`는 맵의 가로/세로 길이입니다.
예를 들어 X=-50~50, Z=-30~30이면 시작=(-50,-30), 크기=(100,60)입니다.
마스크 U는 +X, V는 +Z를 향합니다. 영역 밖은 마스크 가장자리 값을 유지합니다.

두 방식 모두 바닥 색상과 노멀은 **절대 월드 XZ 좌표**로 반복됩니다.
메시를 회전하거나 조각으로 나눠도 같은 월드 위치에서 텍스처 방향이 유지됩니다.
타일링 0.2는 월드 5단위마다 한 번 반복된다는 뜻입니다.
음수 타일링은 절댓값으로 처리하며 0은 작은 양수로 보호합니다.

## 적용 범위와 비용

평지와 완만한 경사에 사용합니다. 수직 절벽은 XZ 투영이 늘어나므로
기존 `Triplanar_Terrain` 등 절벽용 머티리얼을 사용합니다.

텍스처 읽기는 표면 계산 기준 7회입니다.
마스크 1회 + 색상 3회 + 노멀 3회이며 트라이플래너/버텍스 컬러/AO 읽기는 없습니다.
실제 프레임 속도는 화면 점유율과 렌더 패스, 그림자 등에도 영향을 받습니다.

Shader Graph는 URP Lit 출력과 프로퍼티를 구성하고,
`PlanarTerrainRGB.hlsl`의 Custom Function에서 샘플링과 혼합을 처리합니다.
노멀은 월드 공간으로 출력하여 메시의 UV 탄젠트 방향에 영향을 받지 않습니다.

## 화면 확인

빨강·초록·파랑·검정·노랑 마스크에서 재질 선택과 혼합을 확인합니다.
노멀 강도를 모두 0으로 설정했을 때 원래 메시의 표면 방향이 유지되어야 합니다.
월드 마스크 모드에서는 인접 지형 조각들의 시작 위치/크기를 동일하게 설정합니다.
