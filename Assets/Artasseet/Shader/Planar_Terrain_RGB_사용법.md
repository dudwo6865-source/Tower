# 평지 RGB 마스크 셰이더

## 평지와 트라이플래너 함께 칠하기

`Assets/Artasseet/Map/Triplanar_Terrain.shadergraph`도 같은 RGB 마스크를 사용합니다.
기존 색상·노멀·타일링 설정은 유지되며, 버텍스 컬러와 경사 자동 혼합은 RGB 혼합으로 대체됩니다.
트라이플래너의 R은 기존 Main, G는 Grass, B는 Hill 재질입니다.
평지는 R=흙, G=모래, B=퇴적층이며, 채널마다 각 머티리얼에 지정한 텍스처가 표시됩니다.
평지와 절벽에서 같은 재질로 이어지게 하려면 각 채널의 텍스처를 대응시켜 설정합니다.

1. 평지와 절벽을 모두 포함하는 부모 오브젝트를 브러시에 지정합니다.
2. 기존 편집 원본을 열고 `지형의 RGB 머티리얼 함께 등록`을 누릅니다.
   새 원본은 `지형에서 머티리얼과 범위 가져오기`로 머티리얼들을 함께 수집합니다.
3. 등록된 머티리얼을 확인합니다. 불필요한 대상은 `제외`로 뺍니다.
4. Scene 뷰에서 B로 시작하고 칠한 뒤 `PNG 저장 및 머티리얼 적용`을 누릅니다.

저장 시 모든 등록 머티리얼에 동일한 PNG·월드 시작 위치·크기를 적용하고 UV0 모드를 끕니다.
등록은 기존 픽셀과 영역을 변경하지 않습니다. 추가한 지형이 기존 영역 밖이면 새 범위의 원본이 필요합니다.
같은 머티리얼을 쓰는 다른 맵도 저장 결과의 영향을 받으므로 맵별로 머티리얼을 복제합니다.
마스크가 없거나 검정이면 R 재질을 표시합니다. 기존 경사 분포는 자동 변환하지 않습니다.
수직 벽도 마스크는 XZ 기준이므로 같은 XZ의 위아래를 서로 다른 재질로 칠할 수 없습니다.
트라이플래너 텍스처 투영 자체는 3축을 유지하며 AO는 사용하지 않습니다.
트라이플래너의 매끄러움은 기존 공통 Roughness 설정을 유지합니다.

`Planar_Terrain_RGB.mat`을 복제하여 평지 메시의 머티리얼로 사용합니다.
셰이더 목록의 경로는 `Tank/지형/Planar_Terrain_RGB`입니다.
기존 씬의 머티리얼은 자동 교체하지 않습니다.

## 유니티에서 브러시로 칠하기

1. 맵별로 복제한 평지 머티리얼을 지형 조각들에 적용합니다.
2. `Tools > 맵 > RGB 바닥 브러시`를 엽니다.
3. Hierarchy에서 지형 조각들을 포함하는 부모를 선택한 뒤
   `선택한 오브젝트를 지형으로 지정`을 누릅니다.
4. 대상 머티리얼과 XZ 범위를 확인합니다. 필요하면 `지형에서 머티리얼과 범위 가져오기`를 누릅니다.
5. 해상도를 선택하고 `새 편집 원본 만들기`로 `.asset`을 저장합니다.
6. 흙·모래·퇴적층, 반경·강도·경계 단단함을 선택하고 `미리보기 및 칠하기 시작`을 누릅니다.
7. Scene 뷰에서 왼쪽 버튼으로 드래그합니다. Shift는 흙으로 복원하며 Ctrl+Z로 실행 취소합니다.
8. `PNG 저장 및 머티리얼 적용`을 누릅니다. PNG를 연결하고 월드 마스크 좌표와 가져오기 설정을 자동 적용합니다.

지형과 같은 오브젝트에 있는 Collider를 기준으로 커서 위치를 잡습니다.
Collider가 없는 평지는 `Collider 없으면 기준 평면 사용`을 켜고 높이를 지정합니다.
Scene 뷰에 포커스가 있을 때 B로 미리보기·칠하기를 켜거나 끕니다.
칠하기 중 [ 키는 반경 축소, ] 키는 반경 확대입니다.
한 번에 바뀌는 양은 `단축키 반경 변경량`에서 조절하며 기본값은 0.5입니다.
입력창에서 글을 쓰거나 카메라를 조작하는 동안에는 이 단축키가 작동하지 않습니다.
카메라는 Alt 또는 오른쪽 버튼으로 조작하며 Esc로 칠하기를 종료합니다.
절벽 맵 에디터나 Polybrush의 칠하기 모드는 함께 켜지 않습니다.

브러시는 **월드 마스크 방식 전용**입니다. 기존 UV0 마스크의 무늬를 월드 마스크로 자동 변환하지 않습니다.
같은 XZ에 겹쳐 있는 서로 다른 높이의 지형은 같은 마스크 값을 사용합니다.
칠한 원본 `.asset`은 드래그가 끝날 때 자동 저장됩니다. 다시 열 때 이 원본을 지정하거나 더블클릭합니다.
원본에는 픽셀이 보관되므로 다시 PNG를 불러올 필요가 없습니다.
범위와 해상도는 원본 생성 시 확정합니다. 범위를 바꾸려면 새 원본을 만듭니다.

미리보기는 선택한 부모 아래에서 해당 머티리얼을 쓰는 렌더러에만 적용됩니다.
종료·코드 재컴파일·플레이 진입 시 미리보기를 제거하고 원래 렌더러 설정을 복원합니다.
**실제 게임에는 마지막으로 저장한 PNG가 사용됩니다.** 실행 취소 후에도 PNG를 다시 저장해야 반영됩니다.
PNG 파일 자체의 덮어쓰기는 Ctrl+Z의 대상이 아니며, 편집 원본을 실행 취소한 뒤 재저장합니다.

## 텍스처 설정

- R: 기본 흙, G: 모래, B: 퇴적층입니다. 각 재질의 색상과 노멀을 넣습니다.
- 노멀 이미지는 Unity의 Texture Type을 Normal map으로 설정합니다.
- 마스크 이미지는 일반 텍스처로 가져오고 **sRGB를 끕니다**. 정확한 혼합이 필요하면 압축도 끕니다.
- 검정 마스크 또는 마스크 미지정은 기본 흙입니다. RGB 합이 0이 아니면 비율을 정규화합니다.
  예를 들어 노랑(1,1,0)은 흙과 모래를 반씩 섞고, 흰색은 세 재질을 같은 비율로 섞습니다.
- AO는 사용하지 않습니다. 매끄러움은 재질별 수치를 같은 마스크로 혼합합니다.

## 마스크 좌표

`마스크에 메시 UV0 사용`은 기본으로 켜져 있습니다.
섭스턴스 페인터에서 해당 메시의 UV에 맞춰 칠한 RGB 마스크를 그대로 넣습니다.
마스크를 개별 영역에 칠하려면 UV가 서로 겹치지 않아야 합니다.

여러 지형 조각에 큰 마스크 한 장을 사용할 때는 이 옵션을 끕니다.
`월드 마스크 시작 위치 (X,Z)`는 맵의 최소 X/Z 위치,
`월드 마스크 크기 (X,Z)`는 맵의 가로/세로 길이입니다.
예를 들어 X=-50~50, Z=-30~30이면 시작=(-50,-30), 크기=(100,60)입니다.
마스크 U는 +X, V는 +Z를 향합니다. 영역 밖은 마스크 가장자리 값을 유지합니다.

두 방식 모두 바닥 색상과 노멀은 **절대 월드 XZ 좌표**로 반복됩니다.
메시를 회전하거나 조각으로 나눠도 같은 월드 위치에서 텍스처 방향이 유지됩니다.
타일링 0.2는 월드 5단위마다 한 번 반복된다는 뜻입니다.
음수 타일링은 절댓값으로 처리하며 0은 작은 양수로 보호합니다.

## 적용 범위와 비용

평지와 완만한 경사에 사용합니다. 수직 절벽은 XZ 투영이 늘어나므로
기존 `Triplanar_Terrain` 등 절벽용 머티리얼을 사용합니다.

텍스처 읽기는 표면 계산 기준 7회입니다.
마스크 1회 + 색상 3회 + 노멀 3회이며 트라이플래너/버텍스 컬러/AO 읽기는 없습니다.
실제 프레임 속도는 화면 점유율과 렌더 패스, 그림자 등에도 영향을 받습니다.

Shader Graph는 URP Lit 출력과 프로퍼티를 구성하고,
`PlanarTerrainRGB.hlsl`의 Custom Function에서 샘플링과 혼합을 처리합니다.
노멀은 월드 공간으로 출력하여 메시의 UV 탄젠트 방향에 영향을 받지 않습니다.

## 화면 확인

빨강·초록·파랑·검정·노랑 마스크에서 재질 선택과 혼합을 확인합니다.
노멀 강도를 모두 0으로 설정했을 때 원래 메시의 표면 방향이 유지되어야 합니다.
월드 마스크 모드에서는 인접 지형 조각들의 시작 위치/크기를 동일하게 설정합니다.
