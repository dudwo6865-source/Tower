# 튜토리얼 연결 가이드

## 통합 에디터

**Tools > 튜토리얼 > 튜토리얼 에디터**에서 에셋·스테이지·씬 연결을 한 창에서 관리합니다.
스테이지 에디터의 **튜토리얼 에디터에서 관리** 버튼으로 현재 스테이지를 바로 열 수도 있습니다.

1. 가운데에서 새 안내를 만들거나 기존 안내를 선택하고, 페이지 본문·이미지·순서를 편집합니다.
2. 왼쪽에서 스테이지를 선택하고 **선택 안내를 이벤트로 추가**한 뒤 발생 이벤트를 정합니다.
3. 오른쪽의 **씬 연결 찾기**로 컴포넌트를 찾고 UI 참조를 연결합니다. 여러 개면 직접 선택합니다.
   컴포넌트가 없으면 Hierarchy의 항상 활성인 빈 오브젝트를 선택하고 **선택 오브젝트에 관리 컴포넌트 추가**를 누릅니다.
   TutorialController와 TutorialPanel만 추가하며 UI 외형은 만들거나 변경하지 않습니다.
4. 필요하면 **선택 스테이지를 기본 스테이지로 연결**하여 MapLoader에 적용합니다.
   미션 선택 화면에서 전달한 스테이지가 있으면 그 값이 우선합니다.
5. **선택 에셋 저장**과 **연결 컴포넌트의 씬 저장**으로 저장합니다. 씬 저장은 해당 씬의 다른 변경도 저장합니다.

선택한 안내의 연결 오류는 오른쪽에 표시됩니다. 미리보기는 에셋 내용만 보여 주며 씬 UI를 조작하지 않습니다.
MapLoader가 없는 씬은 오른쪽의 **씬 기본 이벤트**에서 설정합니다. 편집은 Undo를 지원하고 플레이 중에는 읽기 전용입니다.

## 1. 씬 UI 연결

UI는 에디터에서 직접 만들며 코드가 위치·크기·폰트·색상·애니메이션을 변경하지 않습니다.

1. 항상 활성화할 빈 오브젝트에 `TutorialController`와 `TutorialPanel`을 붙입니다. 두 컴포넌트는 **패널 루트 밖**에 둡니다.
2. Canvas 아래에 안내 패널, TMP 본문, 다음 Button, 필요한 Image들을 만듭니다.
3. 전체 화면을 덮는 별도 Image를 패널 뒤에 만들고 **Raycast Target**을 켭니다. 기존 게임 UI보다 앞에 놓습니다. 이것이 `입력 차단 배경`입니다. 안내 패널을 이 배경의 자식으로 만들지 마세요. 실습에서는 배경만 꺼집니다.
4. `TutorialPanel`의 `패널 루트`, `본문 텍스트`, `다음 버튼`, `이미지 영역`, `입력 차단 배경`을 연결합니다. 이미지 영역은 서로 다른 오브젝트로 구성하며 배열의 0번부터 번호를 매깁니다. 이미지가 없는 페이지는 모든 이미지 영역을 숨깁니다.
5. `TutorialController > 표시 패널`에 위 `TutorialPanel`을 연결합니다.
6. Canvas의 GraphicRaycaster와 씬의 EventSystem을 확인합니다. 다음 Button의 Navigation은 None을 권장합니다. 버튼 On Click에는 넘기기 함수를 추가하지 않습니다. 코드에서 자동 연결합니다.

패널 전체를 눌러 넘기려면 패널 배경에 Button을 붙이고 `다음 버튼`으로 연결합니다. 버튼이 자식 텍스트·이미지 클릭도 받을 수 있도록 계층과 Raycast Target을 설정합니다. 화면 전체 클릭으로 넘기려면 화면 전체 크기의 Button을 직접 만들어 연결합니다.

입력 차단 배경은 게임 UI를 막고, 코드에서는 유닛 선택·명령·건설·카메라·미니맵과 주요 단축키를 막습니다. 패널을 연 프레임에는 클릭을 무시하고, 각 페이지에 `페이지 클릭 보호 시간(초)`를 적용합니다. 설명을 닫은 프레임과 다음 프레임까지 게임 입력을 차단합니다.

시간 정지 중 패널 애니메이션을 사용한다면 Animator의 Update Mode를 **Unscaled Time**으로 설정합니다.

## 2. 내용 에셋 작성

Project 창에서 **Create > Tank > 튜토리얼 > 안내**를 선택합니다.

- `페이지`: 본문, 이미지, 이미지 영역 번호를 설정합니다. 텍스트만 표시할 수도 있습니다.
- `게임 시간 정지`: 안내가 열릴 때 정지하고 닫히면 기존 배속으로 돌아갑니다. 다른 정지 화면이 남아 있으면 계속 정지합니다.
- `게임 조작 차단`: 시간은 흐르지만 조작만 막는 설명에도 사용할 수 있습니다. 시간 정지가 켜져 있으면 조작도 차단합니다.
- `실행 중 한 번만 표시`: 같은 스테이지 로드 중 한 번만 표시합니다. 스테이지를 다시 로드하면 초기화합니다. 저장 데이터에 영구 기록하지 않습니다.
- `실습 이벤트까지 대기`: 마지막 페이지를 유지하고 `완료 이벤트`가 발생하면 닫습니다. 이 경우 시간 정지와 조작 차단을 모두 끕니다. 완료 이벤트는 마지막 페이지를 표시한 이후에 발생해야 합니다.
- `완료 이벤트 이름`: 완료 이벤트가 사용자 지정일 때만 사용합니다.

실습 안내는 플레이를 가리지 않는 작은 패널로 디자인하는 것이 좋습니다. 현재는 연결한 한 패널을 공통으로 사용하므로 페이지별 배치나 크기는 자동 변경하지 않습니다.

## 3. 스테이지 이벤트 연결

**Tools > 맵 > 스테이지 에디터 > 튜토리얼 이벤트 목록**, 또는 MapConfig 인스펙터에서 편집합니다. `MapLoader`가 있으면 해당 스테이지 목록을 사용합니다. 없으면 `TutorialController > 기본 이벤트 목록`을 사용합니다.

각 항목에서 `발생 이벤트`, `표시할 안내`, 필요한 경우 `웨이브 번호`, `선행 안내`, `이벤트 이름`을 설정합니다.

- 스테이지 시작: 맵 준비와 시작 연출이 끝나면 발생합니다.
- 낮/밤 시작: 시작 페이즈도 포함합니다. 웨이브 번호 0은 모든 웨이브입니다.
- 건물 건설 완료: 플레이어가 배치한 건물의 기능 잠금이 풀리면 발생합니다. 시작 시 배치된 건물은 포함하지 않습니다. 완료 전에 파괴되면 발생하지 않습니다.
- 유닛 생산 완료: 로컬 플레이어의 생산 건물에서 실제 유닛 생성에 성공한 뒤 발생합니다.
- 알 리젠 수 변화: 알 파괴로 구간이 바뀌어 다음 출현부터 한 번에 나오는 수가 달라질 때 발생합니다. 초기 설정·동일 수 구간·미션 완료·출현 한도 소진은 제외합니다. 동시 알 상한 때문에 실제 생성 수가 줄어드는 경우도 제외합니다. `변경 후 알 리젠 수` 0은 모든 변화, 3이면 3개로 바뀔 때만 반응합니다.
- 사용자 지정 이벤트: 이름이 정확히 일치할 때 발생합니다.

같은 이벤트의 안내들은 목록 순서대로 대기열에 들어갑니다. 표시 중이거나 이미 대기열에 있는 같은 에셋은 중복 예약하지 않습니다. `선행 안내`가 설정되어 있으면 그 안내 완료 후에 발생한 이벤트만 처리합니다. 실습 완료 이벤트는 실습을 선행 조건으로 가진 후속 안내에도 전달됩니다. 이전 이벤트를 소급해서 재생하지 않습니다.

### 예시: 설명 → 건설 실습 → 완료 설명

1. **건설 설명** 에셋: 시간 정지와 조작 차단을 켜고 두 페이지를 작성합니다.
2. **건설 실습** 에셋: 두 옵션을 끄고 “타워 하나를 건설하세요.” 한 페이지를 작성합니다. 실습 이벤트까지 대기를 켜고 완료 이벤트를 `건물 건설 완료`로 설정합니다.
3. **건설 완료 설명** 에셋: “잘했습니다. 밤이 되면 적이 진군합니다.”를 작성합니다.
4. 이벤트 목록에 다음 순서로 세 항목을 넣습니다.
   - 스테이지 시작 → 건설 설명. 선행 안내 없음.
   - 스테이지 시작 → 건설 실습. 선행 안내 없음. 첫 설명 뒤 대기열에서 표시됩니다.
   - 건물 건설 완료 → 건설 완료 설명. 선행 안내는 건설 실습.

건물 종류 구분이 필요하면 별도의 사용자 지정 이벤트를 연결합니다. 기본 건설·생산 이벤트는 종류를 구분하지 않습니다.

## 4. 특정 구역과 기존 이벤트 연결

구역 오브젝트에 `TutorialEventTrigger`를 붙이고 `이벤트 이름`과 `아군 유닛 진입 시 실행`을 설정합니다. Collider의 Is Trigger를 켜고 유니티 3D 트리거 조건에 맞게 Rigidbody를 구성합니다. 스테이지의 사용자 지정 이벤트 항목에 같은 이름을 입력합니다. 여러 유닛이 들어와도 안내 에셋의 일회성 설정으로 재표시를 막을 수 있습니다.

기존 UnityEvent에는 `TutorialEventTrigger.RaiseEvent()`를 연결할 수 있습니다. 문자열을 직접 전달하려면 `TutorialController.RaiseCustomEvent(string)`을 연결합니다. 특정 안내를 직접 예약하려면 `TutorialController.Play(TutorialSequence)`를 사용합니다.

## 5. 플레이 확인

- 시작 연출 이후 설명이 뜨고 게임 시간이 멈추는지 확인합니다.
- 첫 클릭, 연속 클릭, 마지막 클릭이 유닛 이동·선택·건설로 전달되지 않는지 확인합니다.
- 페이지마다 이미지가 바뀌고 텍스트 전용 페이지에서는 이미지가 숨겨지는지 확인합니다.
- 실습 중 건설이 가능하고 건설 완료 후 다음 안내로 넘어가는지 확인합니다.
- 같은 이벤트 반복, 다른 안내 동시 발생, 일시정지 메뉴·유물 화면·결과 화면과의 중첩을 확인합니다.
- 다시 시작했을 때 안내가 다시 나오고, 패널 또는 컨트롤러 비활성화 시 시간이 풀리는지 확인합니다.

필수 연결이 빠졌거나 실습에 시간 정지·조작 차단이 켜져 있으면 안내를 예약하지 않고 콘솔 경고를 남깁니다. 대체 UI는 생성하지 않습니다.
