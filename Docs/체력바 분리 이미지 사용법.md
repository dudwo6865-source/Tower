# A안 체력바 분리 이미지

경로: Assets/Artasseet/UI/HealthBars

- unit-frame.png: 일반 유닛용 은색 금속 테두리. 가운데와 바깥은 투명합니다.
- unit-background.png: 일반 유닛용 어두운 빈 체력 영역.
- unit-fill.png: 일반 유닛용 밝은 100% 채움 영역. Image Color로 착색합니다.
- boss-frame.png: 보스용 장갑 테두리. 이름·문양·체력 숫자는 포함하지 않습니다.
- boss-background.png: 보스용 어두운 빈 체력 영역.
- boss-fill.png: 보스용 밝은 100% 채움 영역. Image Color로 착색합니다.

각 .meta 파일은 Sprite (2D and UI), Multiple 모드에서 여백을 제외한 하위 스프라이트 1개를 정의합니다. Project 창에서 PNG 옆 화살표를 펼친 뒤 안쪽 스프라이트를 Image의 Source Image에 연결합니다. 원본 PNG에는 여백이 있지만 하위 스프라이트는 여백을 제외합니다.

PNG는 생성 원본을 보존했으며, Unity에서 RGB 세 채널 모두 R 채널을 사용하도록 설정하여 미세한 색조까지 제거합니다. 알파는 원본대로 유지합니다. 밉맵은 끄고 압축하지 않도록 설정했습니다.

## 연결 순서

1. 체력바 그룹 아래에 Background, Fill, Frame 순서로 Image 세 개를 만듭니다. Frame이 마지막에 그려져 채움 이미지 가장자리를 덮게 합니다.
2. 각 Source Image에 background, fill, frame 스프라이트를 연결합니다. Background와 Frame은 Image Type = Simple, Fill은 Filled / Horizontal / Left로 설정합니다.
3. 배경과 채움의 RectTransform을 같은 위치·크기로 맞추고 테두리 안쪽 영역을 약간 겹쳐 덮도록 조절합니다. 각 이미지는 독립된 레이어이므로 Set Native Size로 세 개의 크기를 같게 만드는 방식은 사용하지 않습니다.
4. 시작 크기 예시: 일반 테두리 240×28, 배경·채움 약 226×16. 보스 테두리 420×63, 배경·채움 약 370×28. 실제 화면에서 테두리 안쪽에 맞게 조절합니다.
5. Fill의 Image Color를 원하는 색으로 설정합니다. 흰색은 무채색 원본이며, 초록·빨강 등으로 자유롭게 착색할 수 있습니다. Background와 Frame도 별도로 착색할 수 있습니다.
6. 세 Image의 Raycast Target을 끄고, WorldHealthBar의 채움 이미지에는 Fill을 연결합니다. 표시 그룹에는 세 레이어를 감싼 CanvasGroup을 연결합니다.
7. 보스 이름과 현재/최대 체력은 별도 TMP 텍스트로 구성합니다. 숫자 텍스트를 WorldHealthBar의 체력 숫자에 연결합니다.

체력이 0%, 50%, 100%일 때 채움이 왼쪽부터 잘 줄어드는지 확인하고, 테두리 밖으로 삐져나오면 Fill과 Background 크기를 함께 줄여 주세요. 디자인 크기와 색은 코드에서 변경하지 않습니다.
