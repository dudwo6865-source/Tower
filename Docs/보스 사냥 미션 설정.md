# 보스 사냥 미션 설정

## 구현 범위

밤 습격과 둥지 원정을 결합한 첫 보스 미션입니다. 다음 순서로 구현했습니다.

1. 출격·후퇴 규칙과 둥지의 보스 1회 생성.
2. 기존 이동·기본 공격을 사용하는 보스 전용 AI.
3. 둥지 안 피해 감소와 누적 체력 유지.
4. 보스 처치 승리, 맵 로더 연결, 스테이지 에디터 설정.
5. 기존 승리 조건 목록 표시, 선택적으로 연결하는 보스 체력 HUD.
6. 기존 자산을 보존하는 보스 프리팹·임시 맵·스테이지 생성 도구.

특수 공격, 격앙, 회복, 수호 구조물, 추가 소환은 포함하지 않았습니다. 보스의 일반 공격은 원본 프리팹의 UnitAttacker와 애니메이션을 사용합니다.

## 확정 행동

- 시작부터 둥지에 보스가 한 마리 있습니다. 낮에 바로 원정할 수 있습니다.
- 첫 출격 밤부터 밤마다 본부를 습격합니다. 기본값은 첫 번째 밤입니다.
- 밤이 됐을 때 둥지에서 교전 중이면 기다립니다. 같은 밤에 교전이 끝나면 출격하고, 아침까지 이어졌으면 그 밤 출격은 건너뜁니다.
- 출격 이후 실제 잃은 체력이 최대 체력의 20%에 도달하면 즉시 공격을 취소하고 후퇴합니다. 둥지에서 받은 피해와 이전 출격의 피해는 새 출격 후퇴 기준에 포함하지 않습니다.
- 아침에는 교전이나 피해량과 관계없이 후퇴합니다.
- 후퇴 중에도 피해를 받고 죽을 수 있습니다. 공격자를 추격하지 않고, 퇴로를 가로막는 적 건물만 공격합니다.
- 복귀한 당일 밤에는 재출격하지 않습니다.
- 체력은 낮밤 전환이나 복귀 시 회복하지 않습니다.
- 실제 둥지 범위 안에서는 방어력 계산 후 받는 피해가 기본 30% 감소합니다. 출격·복귀 여부와 무관하게 위치로 판단합니다.
- 보스는 일반 적 돌연변이 적용에서 제외합니다. 웨이브 스폰 경로를 사용하지 않으므로 일반 공격대 생존 상한이나 아침 예약 취소도 적용되지 않습니다.
- 처치 승리는 보스가 실제 생성된 후 사망한 경우만 인정합니다. 오브젝트 삭제·비활성화·생성 실패는 승리가 아닙니다.
- 보스 처치 프레임의 피해 처리를 마친 뒤 승리합니다. 같은 프레임에 본부가 파괴되면 패배합니다.

교전 판정은 보스 감지 범위 안의 공격 가능한 상대를 기준으로 합니다. 둥지 밖 상대는 현재 사거리 안에서 공격 가능한 경우에만 대응하고, 멀리 추격하지 않습니다. 둥지 밖에서 일방적으로 공격 가능한 장거리 배치가 생기지 않도록 맵에서 확인합니다.

## 새 임시 맵 만들기

1. `Tools > 맵 > 보스 미션 만들기`를 엽니다.
2. `설정을 복사할 스테이지`에 경제·낮밤·보상 기준으로 사용할 MapConfig를 연결합니다.
3. `보스 외형 원본 적 프리팹`에 EntityHealth, UnitAttacker, NavMeshAgent가 있는 일반 적 프리팹을 연결합니다.
4. `플레이어 본부 프리팹`에 Headquarters가 붙은 본부를 연결합니다.
5. 이름, 보스 체력·공격력·이동 속도, 교전 구역 너비와 구역 간 거리를 조절합니다.
6. `새 보스 미션 에셋 생성`을 누릅니다.

`Assets/Data/Stage/BossMission` 아래에 Boss.prefab, BossMap.prefab, BossStage.asset을 만듭니다. 같은 폴더가 있으면 새 이름을 사용합니다. 원본 적·스테이지·맵은 수정하지 않습니다.

- Boss.prefab: 기존 전투 AI와 스포너 수비대 컴포넌트를 제거하고 BossCombatAI를 붙인 복사본입니다.
- BossMap.prefab: 본부 → 중앙 방어 구역 → 추격 구간 → 둥지의 단순 지형과 본부 생성 마커가 있습니다. 런타임 NavMesh 굽기를 켜 둡니다.
- BossStage.asset: 보스 처치만 승리 조건으로 사용합니다. 초기 적과 돌연변이를 끄고 낮부터 시작합니다. 경제·웨이브·보상 등 나머지는 선택한 원본 설정을 따릅니다.

일반 적 스포너, 추가 생산 건물, UI, 장식은 생성하지 않습니다. 본부만으로 병력 생산을 시작할 수 없는 구성이라면 생산 건물의 StageBuildingSpawnPoint도 배치합니다. 기존 본부의 건설 기능으로 생산 건물을 건설할 수 있으면 그대로 사용합니다.

생성 도구는 에디터에서 사용자가 실행하는 기능입니다. 코드 추가만으로 현재 씬이나 로비 미션 목록이 바뀌지는 않습니다. 생성한 BossStage를 스테이지 에디터에서 선택해 테스트하거나, 전투 씬 MapLoader의 `기본 스테이지`에 연결하세요. 정식 등록은 로비 MissionSelectionUI의 `미션 목록`에 추가합니다.

## 기존 맵에 직접 연결하기

1. MapRoot 아래 빈 오브젝트를 만들고 BossNest를 붙입니다. 활성 둥지는 정확히 한 개만 둡니다.
2. `보스 프리팹`에 BossCombatAI를 사용하는 프리팹을 연결합니다. 같은 오브젝트에 EnemyCombatAI 등 다른 전투 AI를 함께 두지 않습니다.
3. 둥지 중심과 `둥지 반경`을 정합니다. 필요하면 범위 안 자식 Transform을 `대기 위치`에 연결합니다.
4. `첫 출격 밤`, `후퇴 피해 비율`, `둥지 피해 감소율`을 설정합니다. 비율 0.2는 20%, 0.3은 30%입니다.
5. MapConfig의 `승리 조건 덮어쓰기`와 `보스 처치 승리 사용`을 켜고 다른 승리 조건을 끕니다.
6. NavMesh를 확인합니다. 보스 프리팹의 NavMeshAgent 종류와 맵의 NavMeshSurface 종류가 일치해야 합니다.

MapLoader는 실제 사용 중인 MapRoot 아래 둥지를 찾아 GameResultManager에 연결합니다. 씬 맵 사용 방식도 같습니다. 로더 없이 테스트할 때는 GameResultManager의 `보스 둥지`와 BossNest의 `낮밤 사이클`을 연결합니다.

보스 체력은 EntityHealth의 `최대 체력`, 공격력·사거리는 UnitAttacker, 이동 속도는 NavMeshAgent에서 조절합니다. BossCombatAI의 `진군 중 최대 추격 거리`와 `추격 포기 후 진군 시간`은 유닛 하나로 보스를 끝없이 유인하는 것을 제한합니다.

## 화면 연결

기존 VictoryConditionHUD는 연결된 `기준 텍스트`를 목록 항목으로 재사용해 보스 목표와 행동 상태를 표시합니다. 폰트·위치·레이아웃은 수정하지 않습니다.

별도 체력 표시가 필요하면 씬 오브젝트에 BossMissionHUD를 붙이고 직접 디자인한 UI를 연결합니다.

- `보스 패널`: 보스 미션에서 표시할 패널. HUD 자신이나 부모는 연결하지 않습니다.
- `보스 이름 텍스트`, `행동 상태 텍스트`, `체력 텍스트`: TMP 텍스트.
- `체력 채움 이미지`: Image Type을 Filled로 설정한 이미지. 코드에서는 fillAmount만 변경합니다.
- `둥지 버프 표시`: 시야 안 보스에게 피해 감소가 적용되는 동안 보여 줄 오브젝트.

체력은 최초 발견 후 표시하며 시야 밖에서는 마지막 확인 값을 유지합니다. UI 참조가 비어 있어도 대체 UI를 만들지 않습니다. 둥지 범위는 Scene 뷰에서 둥지를 선택하면 노란 원으로 확인합니다. 실제 게임에서 쓸 범위 바닥 표현은 맵에 직접 배치하고 반경에 맞춰 디자인합니다.

## 맵 조정과 플레이 확인

임시 맵은 기능 테스트용이며 최종 지형·외형·난이도는 에디터에서 다듬습니다.

- 본부에서 중앙 방어 구역까지 기본 아군 이동 약 10~15초, 중앙에서 둥지까지 약 15~20초를 시작점으로 조절합니다.
- 보스가 중앙 방어선에 도달하는 데 밤 길이의 20~30%를 넘게 쓰면 거리를 줄이거나 밤을 늘립니다.
- 보스의 몸집과 양측 병력이 지나갈 공간을 확보하고, 실제 타워 배치 뒤에도 진입·복귀 경로를 확인합니다.
- 보스 행동을 먼저 확인한 뒤 기존 스포너를 약하게 추가합니다. 일반 공격대는 기존 낮밤 규칙대로 계속 운영됩니다.
- 낮 둥지 교전 중 밤 전환, 교전 종료 후 출격, 교전이 아침까지 이어질 때 출격 생략을 확인합니다.
- 출격 후 20% 피해에서 공격 모션이 취소되고 후퇴하는지, 아침에도 즉시 복귀하는지 확인합니다.
- 후퇴 중 추가 피해·사망, 퇴로를 막는 건물 돌파, 복귀 후 당일 재출격 금지를 확인합니다.
- 여러 밤에 걸친 체력 유지, 둥지 경계의 피해 감소 적용·해제, 낮 원정 처치 승리를 확인합니다.
- 보스와 본부 동시 사망, 생성 위치 오류, 보스 삭제가 잘못된 승리로 처리되지 않는지 확인합니다.
- 재시작, 일시정지, 보스 시야 상실 후 체력 표시를 확인합니다.

## 변경 파일

- `BossSortieRules.cs`: 밤별 출격과 누적 피해·아침 후퇴 판정.
- `BossNest.cs`: 프리팹 검증·생성·둥지 범위·처치 기록.
- `BossCombatAI.cs`: 둥지 교전·본부 습격·추격 제한·후퇴·막힌 건물 돌파.
- `EntityHealth.cs`: 둥지 피해 감소를 공통 피해 계산에 반영.
- `EnemyMutationManager.cs`: 일반 적 돌연변이에서 보스를 제외.
- `MapConfig.cs`, `MapLoader.cs`: 보스 승리 설정과 현재 맵 둥지 연결.
- `GameResultManager.cs`: 실제 보스 사망에 따른 승리와 설정 오류 안내.
- `StageEditorWindow.cs`, `StageEditorWindow.Wave.cs`: 보스 승리 항목·검증·요약.
- `BossMissionSetupWindow.cs`: 원본을 보존하는 보스 미션 생성 도구.
- `VictoryConditionHUD.cs`, `BossMissionHUD.cs`: 목표·행동·시야에 따른 체력 표시.
- `Tests/BossSortie.Tests.ps1`: 출격 규칙 12개 자동 검증.

런타임·에디터 코드의 별도 출력 컴파일과 출격 규칙 12개, 기존 점령 판정 17개 검증을 통과했습니다. 실제 NavMesh 이동·장애물 돌파·애니메이션·밸런스는 위 플레이 항목으로 확인합니다.
