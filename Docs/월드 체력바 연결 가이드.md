# Filled 이미지 체력바 연결

WorldHealthBar는 이제 에디터에서 연결한 Image.fillAmount만 체력 비율에 맞춰 변경합니다. 최대 체력과 관계없이 에디터에서 정한 길이를 유지합니다. 기존의 칸 자동 생성은 제거했으므로, 기존 유닛·건물 프리팹에도 아래 연결을 해야 체력바가 보입니다.

## 기본 구성

1. 유닛 또는 건물 프리팹 안에 Canvas를 만들고 Render Mode를 World Space로 설정합니다.
2. Canvas 아래에 체력바 전체를 묶는 오브젝트를 만들고 CanvasGroup을 붙입니다. Alpha는 표시할 때 사용할 값(보통 1)으로 두고 Interactable과 Blocks Raycasts는 끕니다.
3. 그 아래에 배경 Image, 채움 Image, 테두리 Image를 배치합니다. 배경 → 채움 → 테두리 순서로 그려지도록 Hierarchy 순서를 정합니다. 모든 Image의 Raycast Target을 끕니다.
4. 채움 Image에 Source Image를 넣고 Image Type = Filled, Fill Method = Horizontal, Fill Origin = Left로 설정합니다. 채움 영역의 너비는 최대 체력일 때의 전체 너비로 맞춥니다.
5. 유닛 본체의 WorldHealthBar에서 **채움 이미지**에 채움 Image, **표시 그룹**에 CanvasGroup을 연결합니다.
6. 보스는 그룹 아래에 TextMeshPro 텍스트를 만들고 **체력 숫자**에 연결합니다. 현재 체력 / 최대 체력이 자동 표시됩니다. 일반 유닛에서는 비워 두어도 됩니다. 보스 이름은 별도 텍스트로 에디터에서 설정합니다.

크기·위치·회전·색·폰트·재질은 에디터에서 지정합니다. 코드는 이미지 유형, 색상, 크기, 회전, 재질을 자동 설정하지 않습니다. 아군·적 색상도 각 프리팹에서 설정합니다. Slider는 필요 없습니다.

## 위치와 표시 옵션

- 기본은 **위치 추적 기준점**을 비워 두고 프리팹 자식 Canvas의 위치와 회전을 직접 설정합니다. 자식이므로 유닛의 이동·회전·스케일을 그대로 따릅니다.
- 기존처럼 발밑과 카메라 쪽 오프셋을 사용하려면 체력바 전용 부모 오브젝트를 **위치 추적 기준점**에 연결합니다. 이 경우에만 해당 기준점의 월드 위치를 갱신합니다. 유닛 본체나 유닛의 부모를 연결하면 추적이 해제됩니다. 크기와 회전은 변경하지 않습니다.
- **높이 오프셋**은 Unit/Building의 UnitData가 있을 때 데이터의 healthBarHeightOffset 값을 적용받습니다. 기준점을 연결하지 않으면 이 값과 화면 아래 오프셋은 사용하지 않습니다.
- 보스의 **적 체력바 항상 표시**를 켜면 현재 시야 안에서 계속 표시됩니다. 일반 유닛은 **선택 시 표시**, **피해 후 표시 시간(초)**을 사용하면 됩니다.
- 시야 밖·사망·컴포넌트 비활성화 때 즉시 숨기고, 일반적인 표시/숨김은 **표시 전환 속도**로 조절합니다. 회복은 피격 표시 시간을 연장하지 않습니다.
- 배경·채움·텍스트는 모두 연결한 CanvasGroup 아래에 있어야 함께 숨겨집니다. 프리팹 안의 참조를 연결하면 생성된 각 유닛도 자신의 UI를 사용합니다.
- 기존 모델 뒤 숨김/덮어 그리기 재질은 자동 적용하지 않습니다. 일반 World Space Canvas 재질을 사용하면 지형과 모델에 가려질 수 있으므로 에디터에서 위치와 재질을 조절합니다.

## 확인할 동작

일반 유닛과 보스를 각각 선택해 최대 체력일 때 가득 차고, 절반 피해를 받으면 같은 길이의 바가 절반만 차는지 확인합니다. 보스의 체력 숫자, 최대 체력 변경, 회복, 안개 밖 이동, 사망, 비활성화 후 재활성화도 확인합니다. 참조가 없는 프리팹은 경고를 남기며 UI를 자동 생성하지 않습니다.
