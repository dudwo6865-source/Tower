# 로비 매니저

Lobby 씬의 **Canvas > LobbyManager 컴포넌트**에서 설정합니다.

- 연구 버튼: 기존 LapButton.
- 미션 버튼: 기존 StartButton.
- 정비창 버튼: 기존 ArmoryButton.
- 크레딧 텍스트: 기존 resources의 숫자 텍스트. 저장된 보유량을 표시하고 잔액 변경 시 갱신합니다.
- 씬 정보 텍스트: 기존 함교 텍스트. 로비 표시 이름만 표시합니다. 기본값은 함교입니다.
- 기본 스테이지: 1Stage. 이전 선택 유지가 켜져 있으면 이전에 선택한 스테이지를 우선합니다.

팝업과 이벤트가 비어 있어도 오류 없이 사용할 수 있습니다. 현재는 버튼을 눌러도 팝업을 만들거나 전투 씬으로 이동하지 않습니다.

## 나중에 화면 연결하기

만든 팝업 오브젝트를 **연구 팝업 / 미션 팝업 / 정비창 팝업**에 넣으면 버튼으로 열립니다. 연결된 팝업 중 하나를 열면 나머지를 닫습니다. 팝업이 없는 버튼은 현재 열린 창에 영향을 주지 않습니다. 팝업 닫기 버튼은 `LobbyManager.ClosePopups`에 연결하면 됩니다.

동적 생성이나 다른 처리가 필요하면 **버튼 요청 이벤트**에 동작을 연결합니다. 팝업 연결 여부와 관계없이 이벤트가 실행됩니다. 팝업 슬롯에서 이미 여는 창을 이벤트에서도 다시 열도록 중복 연결할 필요는 없습니다. 매니저가 있는 Canvas 자체를 팝업 슬롯에 넣지 마세요.

미션 선택 화면에서는 `SetSelectedStage(MapConfig)`를 호출합니다. 화면 정보와 다음 전투에서 사용할 `MapLoader.PendingConfig`가 함께 갱신됩니다. 선택을 바꾼 뒤 **스테이지 변경** 이벤트가 호출됩니다.

## 표시 형식

크레딧 표시 형식의 `{0}`은 보유량입니다. `{0:N0}`이면 숫자만, `크레딧 {0:N0}`이면 이름도 표시합니다.

씬 정보 표시 형식에서는 다음 데이터를 사용할 수 있습니다.

- `{0}`: 로비 표시 이름. 기본 함교.
- `{1}`: 선택한 MapConfig의 표시 이름.
- `{2}`: 선택한 MapConfig의 설명.
- `{3}`: 현재 Unity 씬 이름.

기본 로비에서는 `{0}` 형식으로 로비 표시 이름만 표시합니다. `RefreshAll`을 호출하면 텍스트를 다시 갱신합니다. 표시 형식이 잘못 입력되면 기본 형식으로 표시합니다.
