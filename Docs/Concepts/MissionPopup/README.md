# 미션 선택 팝업 콘셉트

내장 이미지 생성 도구로 제작한 디자인 시안 3종입니다. 실제 UI 구현이나 분리된 스프라이트가 아닙니다.

- 01-armored.png: 은색 장갑 프레임과 파란 모서리. 기존 패널 질감에 가장 가까운 구성.
- 02-holographic.png: 얇은 청록 테두리와 단순한 행으로 목록 가독성을 강조.
- 03-console.png: 좁고 세로로 긴 콘솔. 주황색 선택 표시와 출전 버튼으로 로비 미션 버튼의 색상을 연결.

## 참고 자료

사용자가 제공한 함교 로비 화면과 Assets/Artasseet/UI/Texter의 UI_Panler2.png, UI_Name2.png, UI_Button.png를 함께 참조했습니다.

## 생성 지시 요약

기존 로비를 어둡게 처리한 배경 위에 중앙 미션 선택 팝업을 배치합니다. 남색·코발트·은색 금속·청록 조명과 각진 모서리를 유지합니다. 스테이지 사진이나 지도 없이 열린 스테이지 4개를 한 열의 세로 목록으로 표시합니다. 제목은 미션 선택, 행은 스테이지 01~04, 3번 행은 선택 상태입니다. 완료한 행에는 별을 표시하고 하단에 출전 및 닫기 버튼을 배치합니다. 잠긴 스테이지는 표시하지 않습니다. 세 시안은 각각 두꺼운 장갑 프레임, 얇은 홀로그램 패널, 주황 강조의 물리적 콘솔로 차별화합니다. 스테이지 수와 별은 시안용 예시입니다.
