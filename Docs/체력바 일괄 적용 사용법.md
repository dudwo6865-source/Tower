# 공용 체력바 일괄 적용

## 최초 한 번: 공용 체력바 연결

1. Project 창에서 만든 체력바 프리팹을 엽니다. 현재 작업 중인 Assets/Artasseet/UI/HeathBar.prefab도 사용할 수 있습니다.
2. 체력바 프리팹의 맨 위 오브젝트에 WorldHealthBarView 컴포넌트를 추가합니다. WorldHealthBar는 이곳에 붙이지 않습니다.
3. 채움 이미지, 표시 그룹, 체력 숫자(선택)를 확인합니다. 컴포넌트를 처음 추가할 때 Filled 이미지가 하나면 자동 연결하고, 루트 CanvasGroup과 유일한 TMP 텍스트도 자동 연결합니다. 텍스트가 여러 개라면 체력 숫자를 직접 선택합니다.
4. 채움 Image는 Filled / Horizontal / Left, Canvas는 World Space, 표시 그룹 Alpha는 1로 설정합니다. 배경·채움·테두리·숫자는 표시 그룹 안에 배치합니다.
5. 위치 추적 기준점은 보통 비워 둡니다. 유닛 아래에 들어갈 때 사용할 위치·크기·회전을 공용 프리팹에서 정하고 저장합니다.

일반용과 보스용을 별도 프리팹으로 만들면 각 프리팹에서 한 번씩만 연결하면 됩니다. UI를 새로 그리거나 기존 디자인을 코드로 덮어쓰지 않습니다.

## 여러 유닛에 적용

1. Tools > UI > 체력바 일괄 적용을 엽니다.
2. 공용 체력바 프리팹에 준비한 프리팹을 넣습니다.
3. Project 창에서 적용할 유닛·건물 프리팹을 여러 개 선택합니다. 폴더나 씬 오브젝트는 대상이 아닙니다.
4. Project에서 선택한 프리팹 가져오기를 누르고 목록을 확인합니다.
5. 선택한 프리팹에 체력바 적용을 누릅니다. 유닛 본체에 WorldHealthBar가 없으면 추가하고, 체력바를 중첩 프리팹으로 배치하여 참조까지 연결한 뒤 저장합니다.

보스에 항상 표시를 적용하려면 항상 표시 설정도 적용을 켜고 적 체력바 항상 표시를 켭니다. 기본값은 기존 유닛의 표시 설정을 그대로 유지합니다. 일반용과 보스용은 대상을 나누어 각각 적용합니다.

## 기존 작업과 중복 처리

- 같은 공용 체력바가 이미 있으면 새로 만들지 않고 연결만 갱신합니다. 유닛마다 조절한 위치·크기는 유지합니다.
- 다른 체력바, 공용 체력바 바깥을 가리키는 수동 연결, 체력바 여러 개가 발견되면 해당 유닛은 건너뛰고 Console에 이유를 남깁니다.
- 기존 수동 체력바를 공용으로 바꾸려면 해당 유닛 프리팹에서 기존 UI를 정리하고 WorldHealthBar의 연결을 비운 뒤 다시 적용합니다. 도구는 기존 UI를 자동 삭제하지 않습니다.
- 대상 프리팹 루트에는 EntityHealth와 SelectableEntity가 필요합니다. 누락된 유닛은 Unit/Building의 필요 컴포넌트 추가 기능으로 먼저 구성합니다.
- 현재 프리팹 모드로 열어 둔 대상, 읽기 전용 에셋, 순환 참조가 생기는 대상은 저장하지 않습니다.
- 기반 프리팹과 변형 프리팹을 함께 선택하면 기반을 먼저 처리합니다. 가능하면 공통 기반 프리팹에 먼저 적용하고 변형은 상속받아 사용하세요.
- 적용 버튼은 프리팹 파일을 직접 저장하며 Ctrl+Z로 되돌리는 작업이 아닙니다. 실행 결과에 적용 수와 건너뜀·실패 수가 표시됩니다.

이후 공용 프리팹의 이미지·색·배치를 바꾸면 해당 항목을 개별 덮어쓰지 않은 유닛에도 반영됩니다. WorldHealthBarView의 연결 대상 자체를 바꾼 경우에는 일괄 적용을 다시 눌러 유닛 본체의 연결도 갱신합니다. 런타임 자동 생성은 하지 않습니다.

## 에디터 확인 항목

새 유닛 두 개에 적용하여 각자의 체력바를 참조하는지 확인합니다. 같은 대상에 다시 적용해 체력바 개수가 늘지 않는지, 공용 프리팹 색상 변경이 반영되는지, 유닛별 위치 조절 후 재적용해도 위치가 유지되는지 확인합니다. 기존 수동 연결 대상은 그대로 남아야 하며, 플레이 중 피격과 안개 표시도 확인합니다.
