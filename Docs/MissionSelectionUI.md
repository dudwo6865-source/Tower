# 미션 선택 UI 연결

## 1. 미션 항목 하나 설정

현재 만든 목록에서 항목 하나만 견본으로 남기고 나머지 복제 항목은 삭제합니다. 견본 항목 루트에 `MissionListItemUI`를 추가합니다. Button이 없으면 자동으로 추가됩니다.

- 선택 버튼: 항목 전체를 누르는 Button
- 미션 번호 텍스트 / 미션 이름 텍스트: 항목 안의 TMP 텍스트
- 항목 배경 이미지 / 번호 배지 이미지: 상태에 따라 교체할 Image
- 일반 배경 / 선택 배경, 일반 번호 배지 / 선택 번호 배지: 원하는 Sprite. 일반 이미지를 비워두면 현재 Image의 이미지를 사용합니다.
- 선택 표시 오브젝트: 선택 화살표 등 선택할 때만 켤 자식 오브젝트. 없으면 비워둡니다.
- 별 이미지 목록: 왼쪽부터 별 Image 3개. 획득한 별과 미획득 별 Sprite를 지정합니다. 원본 별 이미지 색상을 그대로 쓰려면 두 별 색상을 모두 흰색으로 설정합니다.

견본을 프리팹으로 저장해도 되고 씬 안에 그대로 두어도 됩니다. 생성되는 항목의 연결은 모두 견본의 자식 UI를 가리키도록 지정합니다. 항목 Button의 Target Graphic에는 배경 Image를 연결하고, 위를 덮는 장식 Image/TMP의 Raycast Target은 꺼두면 입력을 확인하기 쉽습니다.

## 2. 팝업 설정

미션 팝업 루트에 `MissionSelectionUI`를 추가합니다.

- 항목 원본: 1번에서 설정한 MissionListItemUI
- 항목 생성 위치: Scroll View → Viewport → Content
- 스크롤 뷰: 해당 ScrollRect
- 출발 버튼 / 닫기 버튼: 하단 버튼
- 로비 매니저: 기존 LobbyManager. 비워두면 현재 로비의 싱글톤을 사용합니다.
- 전투 씬 이름: 기본값 Battle. Build Settings에 등록된 전투 씬 이름입니다.
- 빈 목록 안내: 미션이 없을 때만 보여줄 안내 오브젝트. 선택 사항입니다.

Content에는 Vertical Layout Group과 Content Size Fitter(Vertical Fit = Preferred Size)를 설정합니다. Content의 위쪽 앵커와 피벗 Y를 1로 맞추고, ScrollRect의 Content도 같은 오브젝트를 지정합니다. 항목에는 Layout Element로 원하는 Preferred Height를 지정합니다. 수동 배치한 다른 항목들은 자동으로 지워지지 않으므로 견본 외의 기존 복제 항목은 정리합니다. 씬 견본은 실행 시 숨겨지고, 등록된 유효한 스테이지 수만큼 복제본이 생성됩니다.

## 3. 스테이지와 로비 버튼 연결

MissionSelectionUI의 미션 목록에 원하는 수만큼 항목을 추가하고 각 스테이지에 MapConfig 에셋을 넣습니다. 등록 순서대로 표시됩니다. 미션 번호를 비우면 01, 02처럼 등록 순서가 표시되고, 표시 이름을 비우면 MapConfig의 표시 이름이 표시됩니다. 스테이지가 비어 있는 항목은 건너뜁니다. 미해금 미션도 목록에 표시하며, 이전 미션 클리어 여부로 선택 가능 상태를 자동 판정합니다.

기존 LobbyManager의 **미션 팝업**에 MissionSelectionUI가 붙은 팝업 루트를 연결합니다. 기존 미션 버튼을 누르면 팝업이 켜지고 목록이 갱신됩니다. 항목·출발·닫기의 On Click에는 같은 기능을 중복으로 등록하지 않습니다. 컴포넌트가 자동으로 연결합니다.

이전 선택이 목록에 있고 해금되었으면 유지하고, 아니면 첫 미션을 선택합니다. 별은 각 MapConfig.StageId에 저장된 최고 클리어 기록을 표시합니다. 출발하면 선택한 MapConfig를 MapLoader.PendingConfig에 전달하고 Battle 씬을 엽니다. Battle 씬에 MapLoader가 있어야 데이터가 적용됩니다.

## 미해금 상태

첫 번째 유효한 미션은 기본 해금됩니다. 이후 미션은 목록에서 바로 이전의 유효한 스테이지를 클리어하면 해금됩니다. 비어 있는 등록 칸은 건너뛰며, 미션 번호 텍스트가 아니라 목록 순서가 기준입니다. 별 0개로 클리어해도 해금되고, 저장에 성공한 클리어 기록으로 다음 실행에도 유지됩니다. 각 스테이지는 서로 다른 StageId를 사용해야 합니다.

MissionListItemUI의 미해금 상태 항목에서 미해금 배경·번호 배지 Sprite, 잠금 표시 자식 오브젝트, 잠금 안내 TMP 텍스트를 연결합니다. 모두 선택 사항이며 비워도 기본 이미지가 흐려지고 선택 버튼이 비활성화됩니다. 미해금 투명도는 기본 0.45이며, 색상 표현만 사용하려면 1로 설정합니다. 잠금 안내 텍스트는 미션 이름과 별도의 텍스트로 연결합니다. 팝업을 다시 열거나 Rebuild를 호출하면 해금 상태를 새로 반영합니다.

## 에디터 확인 항목

- 서로 다른 스테이지 2개를 등록했을 때 견본은 숨고 항목 2개가 표시되는지 확인합니다.
- 두 번째 항목을 누르면 선택 배경과 배지가 바뀌고, 다시 열었을 때 목록이 중복되지 않는지 확인합니다.
- 미션 목록을 비우면 출발 버튼이 비활성화되는지 확인합니다.
- 출발 후 선택한 MapConfig가 전투 씬에 적용되는지 확인합니다.
- 클리어 후 돌아와 해당 미션의 최고 획득 별이 표시되는지 확인합니다.
- 신규 기록에서 첫 미션만 선택 가능하고, 첫 미션을 별 0개로 클리어해도 두 번째 미션이 열리는지 확인합니다.
- 잠긴 항목을 누르거나 SelectMission을 직접 호출해도 선택이 바뀌지 않는지 확인합니다.
