# 알 파괴 미션 설정

알은 어느 순서로든 파괴할 수 있습니다. 알을 하나 파괴하거나 부화시키면 다음 단계의 제한 시간으로 새로 시작합니다. 남은 시간은 이월하지 않습니다. 시간 초과 시 우선순위가 가장 높은 알 하나만 부화하며, 다음 알의 타이머는 즉시 시작합니다.

모든 알을 처리하고 부화 몬스터까지 모두 처치하면 승리합니다. 본부 파괴는 패배입니다. 도입 연출·일시정지·게임 종료 중에는 부화 타이머가 흐르지 않습니다. 같은 프레임에 마지막 목표와 본부가 파괴되면 패배가 우선합니다.

## 1. 스테이지

`Tools > 맵 > 스테이지 에디터`에서 사용할 스테이지를 선택합니다.

- 승리 조건 덮어쓰기와 **알 파괴 미션 사용**을 켭니다.
- 생존·스포너 전멸·거점 점령·보스 처치 승리는 끕니다. 다른 조건을 함께 켜면 그 조건으로 먼저 승리할 수 있습니다.
- **단계별 제한 시간(초)**에 `300, 240, 180, 120`을 입력합니다. 알 3개면 앞의 세 시간만 사용합니다. 알 개수 이상 입력해야 하며, 모든 시간은 양수이고 뒤로 갈수록 짧아야 합니다.
- `MapLoader`가 사용하는 스테이지 에셋을 수정해야 실제 플레이에 적용됩니다.

## 2. 맵과 알

맵 프리팹의 `MapRoot` 오브젝트에 **EggMissionController**를 하나 붙입니다. 그 아래에 알 오브젝트를 3~4개 배치합니다. 알은 미리 씬/프리팹에 배치하며 실행 중 자동으로 만들지 않습니다.

각 알에 필요한 컴포넌트:

- **SelectableEntity**: `종류 = Building`, `소유자 ID = 적 진영 ID`로 설정합니다. 아군 ID와 달라야 합니다. 클릭·공격할 수 있도록 Collider를 연결합니다.
- **EntityHealth**: `최대 체력`, `방어력`, `사망 이펙트 프리팹`을 설정합니다.
- **MonsterEgg**: `목표 이름`, `부화 우선순위`, `부화 몬스터 프리팹`, `부화 위치`를 지정합니다. 우선순위는 작은 수가 먼저이며 같으면 계층 순서입니다.
- **FogOfWarVisibility**: 기존 적 건물처럼 시야에 따라 보이게 하려면 붙입니다.
- **GridFootprint**는 선택 사항입니다. 알 위치에서 부화시키려면 `NavMesh 구멍 뚫기`를 끄세요. 별도의 부화 위치를 연결할 경우 알 바깥의 이동 가능한 위치를 사용합니다.

알에는 `EnemySpawner` 또는 전투 AI를 붙이지 않습니다. 알을 별도 스포너로 등록하면 일반 스포너 승리 조건과 혼동할 수 있습니다.

## 3. 부화 몬스터

`MonsterEgg > 부화 몬스터 프리팹`에는 **EnemyCombatAI**가 붙은 적 프리팹을 연결합니다. `EntityHealth`, `UnitAttacker`, 활성 `NavMeshAgent`도 필요합니다. `BossCombatAI`는 둥지 미션 전용이므로 연결하지 않습니다.

- `체력 배율` 기본 3, `공격력 배율` 기본 2, `이동 속도 배율` 기본 1입니다. 프리팹 수치를 기준으로 적용합니다.
- 웨이브 스폰 수·간격·생존 상한과 무관하게 한 마리씩 부화합니다. 스탯에는 위 배율과 기존 공통 적 생성 기능의 누적 돌연변이가 적용됩니다.
- 부화 직후 본부로 진군하며, 주변 일반 적의 분대 목표를 따라가지 않습니다.
- 알이 받은 피해는 부화 몬스터에게 이어지지 않습니다. 부화 몬스터는 자신의 최대 체력으로 시작합니다.
- 부화 이펙트는 선택 사항입니다. 파괴 이펙트와 별도로 연결합니다.
- NavMesh 생성 실패나 목표의 비정상 삭제는 콘솔에 오류를 남기고 미션 진행을 멈춥니다. 알을 제거하거나 승리로 간주하지 않습니다. 설정을 수정한 후 다시 실행하세요.

## 4. 목표 표시와 HUD

**MonsterEgg > 다음 부화 표시**에 직접 만든 자식 표시 오브젝트를 연결합니다. 현재 부화 예정인 알의 표시만 켜며 외형·위치·크기·색상은 변경하지 않습니다. 알 본체나 공통 부모를 연결하지 마세요. 안개 밖에서도 목표 위치를 보여줄지는 표시 오브젝트의 시야 설정으로 정합니다.

기존 **VictoryConditionHUD**의 `기준 텍스트`와 `조건 목록 부모` 연결을 그대로 사용합니다. 기준 텍스트를 반복 항목으로 복제해 남은 알 수, 다음 부화까지의 시간, 대상 이름, 살아 있는 부화 몬스터 수를 표시합니다. 새 패널이나 디자인은 자동 생성하지 않습니다. 텍스트가 두 줄이므로 프리팹과 Layout Group에서 높이를 확보하세요.

`MapLoader` 없이 시험할 때는 `GameResultManager`에서 `알 파괴 미션 사용`을 켜고 `알 미션`에 컨트롤러를 직접 연결하며 `단계별 제한 시간(초)`을 설정합니다.

## 빠른 플레이 확인

제한 시간을 `15, 10, 7, 5`로 줄이면 빠르게 확인할 수 있습니다.

1. 부화 예정이 아닌 알을 파괴해도 다음 시간이 시작되는지 확인합니다.
2. 시간을 초과해 지정된 알 하나만 부화하고 몬스터가 본부로 진군하는지 확인합니다.
3. 몬스터와 교전하는 동안 다음 타이머가 계속 줄어드는지 확인합니다.
4. 마지막 알을 부화시킨 후 몬스터를 처치해야 승리하는지 확인합니다.
5. 일시정지 중 시간 유지, 여러 알 동시 파괴, 본부 파괴 시 패배를 확인합니다.

진행 규칙 자동 검사는 `Tests/EggMission.Tests.ps1`로 실행합니다.

## 5. 대기·부화 애니메이션과 이미션 맥박

알 본체의 자식으로 모델을 두고 **Animator와 MonsterEggAnimation을 같은 모델 오브젝트에** 붙입니다. MonsterEggAnimation은 알 본체와 같은 오브젝트에 붙이지 않습니다. 소환 후 모델만 분리해 남은 껍질 애니메이션을 재생하기 때문입니다. 모델 아래에는 시각 효과와 렌더러만 두고 EntityHealth·SelectableEntity 등 게임플레이 컴포넌트는 본체에 둡니다.

1. Animator Controller에 `Idle`, `Hatch` 상태를 만들고 각각 평상시 클립과 부화 클립을 연결합니다. Idle은 Loop Time을 켜고, Hatch는 끕니다. 기본 상태는 Idle입니다. 자동 전이·트리거는 필요하지 않으며, 클립에서 Animator 속도를 직접 변경하지 않습니다.
2. MonsterEggAnimation의 `대기 상태 이름 = Base Layer.Idle`, `부화 상태 이름 = Base Layer.Hatch`, `애니메이션 레이어 = 0`을 설정합니다. 다른 이름이나 레이어라면 실제 전체 경로를 입력합니다.
3. MonsterEgg의 `알 애니메이션`에 자식의 MonsterEggAnimation을 연결합니다. 비워도 자식에서 찾습니다. 이 컴포넌트가 전혀 없는 기존 알은 즉시 부화 동작을 유지합니다.
4. 부화 클립의 몬스터 소환 프레임에 Animation Event **OnEggHatch**를 넣습니다. 인수는 없습니다. FBX 클립이면 모델 Import Settings의 Animation 탭에서 이벤트를 추가합니다.
5. 부화 클립 마지막 프레임 직전에 **OnEggHatchFinished** 이벤트를 넣습니다. 소환 이벤트보다 뒤에 있어야 합니다. 몬스터 소환 후 알 본체는 제거되고 모델은 남은 애니메이션을 재생한 뒤 사라집니다.

현재 부화 예정인 알만 제한 시간이 줄어들수록 가속합니다. `평상시 대기 속도` 기본 1, `부화 직전 대기 속도` 기본 3이며 `긴장도 변화 곡선`으로 빨라지는 시점을 조절합니다. 부화 상태는 별도의 `부화 재생 속도`(기본 1)를 사용합니다. 소환 이벤트 전 알을 파괴하면 부화가 취소됩니다. 다음 알의 타이머는 소환 이벤트가 아니라 **부화 애니메이션 시작 시점**부터 흐르며, 부화 중인 알이 남으면 승리하지 않습니다.

`부화 이벤트 대기 한도(초)`는 기본 15초입니다. 부화 클립 재생 시간보다 길게 설정하세요. 소환 이벤트가 없으면 오류를 남기고 미션을 멈추며 자동 소환하지 않습니다. 소환 후 종료 이벤트가 누락된 경우에는 한도에 도달하면 껍질만 정리합니다. 시야 밖에서도 이벤트가 실행되도록 Animator는 실행 중 Always Animate, 일반 게임 시간으로 재생합니다.

이미션 설정:

- `발광 렌더러`에 알 모델의 MeshRenderer 또는 SkinnedMeshRenderer를 연결합니다.
- 원본 머티리얼에서 이미션 기능을 켜고 이미션 맵을 설정합니다. `발광 색 프로퍼티` 기본값은 `_EmissionColor`이며 Shader Graph에서 다른 Reference를 사용하면 그 이름을 입력합니다.
- `발광 색`, `최소 발광 강도`, `평상시 최대 발광 강도`, `부화 직전 최대 발광 강도`로 밝기 범위를 조절합니다. 기본 강도는 0.1 / 1 / 5입니다.
- `평상시 맥박(회/초)`, `부화 직전 맥박(회/초)`로 주기를 조절합니다. 기본값은 0.6 / 2.5입니다.
- `맥박 밝기 곡선`은 한 주기 안의 밝기 모양입니다. 기본은 두 번 뛰고 쉬는 형태입니다. `긴장도 변화 곡선`은 대기 애니메이션 속도와 맥박의 속도·최대 밝기에 함께 적용됩니다.
- 원본 머티리얼을 변경하지 않으며 알마다 독립적으로 맥박을 표시합니다. 같은 렌더러의 이미션을 다른 컴포넌트에서도 동시에 제어하지 마세요. 색·강도·주기는 플레이 중 조절할 수 있고 렌더러 목록과 프로퍼티 이름은 실행 전에 설정합니다.

플레이 시 소환 프레임 일치, 부화 중 파괴, 시야 밖 부화, 일시정지, 반복 이벤트에서 한 마리만 생성되는지 함께 확인하세요.
