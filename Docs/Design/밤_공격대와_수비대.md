# 밤 공격대와 스포너 수비대

## 확정 규칙

- 웨이브는 낮과 밤 한 주기입니다.
- 공격대는 밤에만 출격합니다. 밤 시작, 밤 길이의 1/3, 2/3 시점에 세 번 나눠 출격합니다.
- 스포너 한 개의 밤 전체 총량을 3등분합니다. 나머지는 앞 차수부터 한 명씩 배분합니다. 20명은 7/7/6, 60명은 20/20/20입니다.
- 이전 공격대를 전멸시켰는지와 관계없이 시간에 따라 다음 차수를 출격시킵니다.
- 수비대는 별도 정원으로 관리합니다. 첫 배치 및 매일 아침에 부족분만 보충합니다.
- 부족분 = 최대(0, 정원 - 생존 수 - 보충 예약 수). 정원 20명 중 5명이 사망했다면 5명만 보충합니다.
- 같은 낮 동안 수비대가 죽더라도 즉시 보충하지 않습니다. 다음 아침까지 기다립니다.
- 근접 스폰과 피격 스폰은 설정·타이머·감지·이벤트 처리까지 제거했습니다.
- 기존 파괴 방출은 유지합니다. 필요하지 않으면 `파괴 시 스폰 수`를 0으로 설정합니다.

## 공격대 총량과 출격

`Tools > 맵 > 스테이지 에디터`의 웨이브 적 구성은 스포너 한 개의 밤 기본 총량입니다.
구성이 비어 있으면 스포너의 `적 프리팹 목록`과 `밤 총 출격 수`를 사용합니다.
이 총량에 웨이브 스폰 수 배율과 추가 수, 밤 보정을 적용한 뒤 세 차수로 나눕니다.
종류 구성과 기본 총량은 밤이 시작할 때 확정합니다.

예: 밤 길이 90초, 총량 60명이면 0초/30초/60초에 각각 20명을 출격 예약합니다.
실제 오브젝트 생성은 기존 EnemySpawnScheduler의 프레임당 생성 예산에 따라 분산됩니다.

공격대 생존 상한에는 공격대 생존 수와 생성 예약 수만 포함하고 수비대는 포함하지 않습니다.
상한에 막힌 출격 물량은 해당 밤 동안 자리가 생기면 생성합니다.
밤이 끝나면 아직 생성되지 않은 공격대 물량을 취소합니다. 다음 날 새 물량과 겹쳐 쌓지 않습니다.
스포너 파괴 시에도 해당 스포너의 미생성 공격대와 수비대 보충 예약은 취소합니다.
파괴 방출 예약은 스포너 파괴 후에도 실행하되 게임이 끝나면 생성하지 않습니다.

밤 도중 활성화되거나 만들어진 스포너는 이미 지난 차수까지 현재 밤의 물량을 예약합니다.
낮밤 매니저가 없는 씬은 출격·아침 보충을 진행하지 않습니다.

## 수비대 설정과 행동

스포너 인스펙터에서 다음을 설정합니다.

- `수비대 정원`: 기본 20. 0이면 수비대를 생성하지 않습니다.
- `수비대 프리팹 목록`: 비우면 기존 `적 프리팹 목록`을 사용합니다. 웨이브 적 구성은 공격대에만 사용합니다.
- `수비대 방어 반경`: 기본 18m. 이 범위를 벗어나도 교전 중인 적이 있으면 계속 추격하고, 적이 없어지면 최초 배치 지점으로 복귀합니다. 복귀 중 적이 나타나면 다시 교전합니다. 추격 한도는 수비대 프리팹의 `EnemySpawnerGuard` > `최대 추격 거리`(0 = 무제한)로 정합니다.

수비대는 밤에도 본부로 진군하지 않으며 공격대 분대를 따라가지 않습니다.
각자의 배치 지점으로 복귀하므로 스포너 중심 한 점에 전부 몰리지 않습니다.
수비대 정원에는 웨이브 스폰 수 배율과 돌연변이 스폰 수 증가를 적용하지 않습니다.
능력치는 생성 시점의 웨이브 보정과 누적 돌연변이를 적용하며, 기존 수비대도 새 능력치 돌연변이를 받습니다.
활동 시작 웨이브에 도달하지 않은 스포너는 수비대를 보충하거나 공격대를 출격시키지 않습니다.
밤부터 시작하는 스테이지도 첫 활성 시 수비대를 한 번 배치합니다.

## 돌연변이 연결

스폰 수 돌연변이는 아직 출격 시점이 되지 않은 공격대에만 적용합니다.
차수별 기본 적을 처리할 때 증가분을 적립하고 소수점은 스포너별로 이월합니다.
이미 출격 예약한 물량에는 나중에 나온 스폰 수 돌연변이를 소급하지 않습니다.
실제 생성 시점에는 최신 능력치 돌연변이를 적용합니다.
수비대와 파괴 방출 수에는 스폰 수 돌연변이를 적용하지 않습니다.

## 기존 설정 전환 시 확인

- 기존 `1회 스폰 수` 값은 `밤 총 출격 수`로 이어집니다. 적 구성 없이 쓰던 스포너는 반드시 밤 전체에 맞게 수치를 조절하세요.
- 기존 `주기 스폰` 사용 여부는 `밤 공격대 사용`으로 이어집니다.
- 기존 스폰 간격과 웨이브 간격 배율은 제거했습니다. 출격 간격은 밤 길이로만 결정합니다.
- 적 구성의 총량에도 이제 스폰 수 배율과 추가 수가 적용됩니다. 밤 총량 미리보기에서 최종 수치를 확인하세요.
- 스포너 인스펙터에서 공격대 출격 차수·상한 대기 수·수비대 생존 및 보충 예약 수를 확인할 수 있습니다.
- 초기 배치 적(InitialEnemyPlacer)은 스포너 수비대와 별개입니다. 기존 초기 적과 수비대가 중복 배치되지 않도록 스테이지 구성을 확인하세요.

## 검증

- 실제 분할 계산 코드로 총량 0~1000의 합계 보존과 차수별 수 차이가 최대 1명임을 확인했습니다.
- 수비대 부족분 6개 사례: 사망 5명, 보충 예약 포함, 정원 유지, 정원 초과, 전원 예약 중, 정원 0을 확인했습니다.
- 런타임·에디터 코드를 별도 출력 경로로 컴파일합니다.
- 플레이 확인 항목: 90초 밤의 0/30/60초 출격, 아침에만 5명 보충, 밤에도 수비대 유지, 방어 범위 이탈 후 복귀, 스포너 파괴 후 예약 취소, 생존 상한 처리.
