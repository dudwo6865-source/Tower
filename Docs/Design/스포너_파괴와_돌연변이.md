# 스포너 파괴와 돌연변이

갱신일: 2026-10-15

상태: 초기 돌연변이 구현 완료. 판 밖 추가 보상과 방어력은 후속 작업입니다.

## 기획 의도

스포너 파괴는 보상과 빠른 승리를 위해 위험을 감수하는 선택입니다.
플레이어는 스포너를 남겨두고 목표 웨이브까지 버티거나, 스포너를 파괴해 유물을 얻는 대신 무작위 돌연변이로 적을 강화합니다.
어떤 효과가 나올지는 파괴 후 공개합니다. 파괴로 전체 위협이 반드시 줄어드는 것은 아닙니다.

이 선택을 제공하는 스테이지는 생존 승리를 허용합니다. 전멸 승리도 허용하면 모든 스포너를 파괴해 조기에 승리할 수 있습니다.

## 확정된 초기 범위

- 파괴 1회에 효과 하나를 추첨합니다.
- 계열은 적 스폰 수 증가와 적 능력치 증가, 두 가지입니다.
- 능력치 계열은 공격력·체력·이동 속도 중 **하나만** 올립니다.
- 능력치 강화는 **현재 살아 있는 적과 이후 생성되는 적 모두**에 적용합니다. 초기 배치 적도 포함합니다.
- 적용 대상은 설정된 적 소속 ID의 유닛입니다. 아군과 스포너 등 건물은 강화하지 않습니다.
- 스폰 수 증가는 **주기 스폰에만** 적용합니다. 근접·피격·파괴 방출의 수는 그대로입니다.
- 효과는 해당 판 동안 유지하며 같은 효과를 다시 뽑으면 증가율을 합산합니다. 웨이브가 바뀌어도 유지합니다.
- 방어력은 능력치 시스템을 추가한 뒤 후보에 넣습니다. 적 유형 추가는 후속 확장입니다.

## 첫 테스트 기본값

수치는 스테이지 에디터에서 변경할 수 있는 시작값입니다.

- 스폰 수 계열 확률: 50%. 추첨 시 주기 스폰 수 +20%.
- 능력치 계열 확률: 나머지 50%. 공격력·체력·이동 속도의 추첨 가중치는 각각 1입니다.
- 공격력: +10%.
- 체력: +15%.
- 이동 속도: +5%.
- 적 소속 ID: 2.

증가율이 0인 효과와 추첨 가중치가 0인 능력치는 후보에서 제외합니다.
한 계열에 유효한 후보가 없으면 다른 계열을 사용하고, 전체 후보가 없으면 효과를 발생시키지 않습니다.
현재는 별도의 누적 상한이 없으며 스포너 파괴 횟수가 누적 횟수를 결정합니다.

## 능력치 적용 규칙

최종 능력치는 기본 능력치 × 웨이브 배율 × (1 + 돌연변이 누적 증가율)로 계산합니다.
체력 +15%를 두 번 얻으면 돌연변이 배율은 1.30입니다. 1.15를 두 번 곱하지 않습니다.

기존 적의 체력이 증가하면 **현재 체력 비율을 유지**합니다.
예를 들어 현재 체력 40 / 최대 체력 100인 적에게 +15%가 적용되면 46 / 115가 됩니다.
사망한 적은 되살리지 않습니다.

신규 적은 웨이브 능력치를 적용한 뒤 실제 생성 시점의 누적 돌연변이를 적용합니다.
생성 대기열에 예약된 적도 실제 등장할 때 최신 돌연변이를 받습니다.
근접·피격·파괴 방출로 생성되는 적도 능력치 강화는 받습니다.

## 주기 스폰 수 계산

기본 주기 스폰 적 하나를 예약할 때마다 누적 증가율만큼 추가 물량을 적립합니다.
+20%이면 기본 적 5마리당 추가 적 1마리를 생성합니다. 소수점은 스포너마다 이월합니다.
추가 적은 해당 증가분을 발생시킨 기본 적과 같은 프리팹을 사용하고, 추가 적이 다시 추가 적을 발생시키지는 않습니다.

웨이브의 적 구성 목록은 기본 물량입니다. 돌연변이 추가 적은 목록을 소모하지 않아 **실제 총 적 수가 증가**합니다.
이미 생성한 적에 소급해 추가 물량을 부여하지 않습니다.

추가 적도 생존 상한과 프레임별 생성 예산을 따릅니다.
상한에 막힌 증가분은 스포너 내부에 보관하고, 다음 주기 스폰 시 자리가 있으면 먼저 예약합니다.
기본 구성을 다 내보냈어도 이 증가분이 남아 있으면 주기 스폰을 계속 확인합니다.
이월된 증가분과 소수점은 웨이브가 바뀌어도 유지합니다. 이월된 적은 적립 당시 웨이브 능력치와 생성 당시 돌연변이를 받습니다.
스포너 파괴 시 아직 생성 대기열에 예약하지 못한 추가 물량은 더 이상 내보내지 않습니다.
이미 생성 대기열에 예약한 적은 기존 동작처럼 생성되지만, 승패가 확정되면 생성하지 않습니다.

## 파괴와 승리 처리

일반 파괴는 사망 표시 → 돌연변이 추첨·기존 적 강화 → 유물 후보 제시 → 파괴 방출 예약 순서입니다.
활성화 전 스포너를 부숴도 돌연변이와 유물은 발생합니다. 기존의 활성화 전 파괴 방출 없음 규칙은 유지합니다.

파괴 시 기존 전멸 승리 조건이 충족되면 새 돌연변이·유물 선택·파괴 방출을 생략합니다.
기존 파괴 실적 집계는 유지하고 GameResultManager가 승리를 확정합니다.
생성 대기 중인 스포너와 판정 시작 대기 시간도 승리 조건에 포함합니다.
전멸 승리를 사용하지 않거나 아직 조건이 충족되지 않았다면 일반 파괴로 처리합니다.

여러 스포너가 연달아 파괴되면 돌연변이는 각각 발생하며, 결과 알림과 유물 선택 보상은 순서대로 표시합니다.
승패가 확정되면 남은 판 안의 선택 화면과 돌연변이 알림은 닫습니다.

## 보상 정책: 일부 미정

해당 판의 보상은 기존 유물입니다.
판 밖으로 가져가는 추가 보상은 다음 두 안 중 결정하지 않았습니다.

- 별도의 특별 자원 지급.
- 스포너 파괴에 따른 기존 보상 추가 지급.

지급량·지급 시점·승패에 따른 보존 조건·사용처는 후속 기획입니다.
이번 구현에는 재화 지급이나 영구 저장을 넣지 않았습니다. 기존 파괴 스포너 수 통계를 후속 정산에 연결할 수 있습니다.

## 에디터 사용법

1. `Tools > 맵 > 스테이지 에디터`에서 적용할 스테이지를 선택합니다.
2. 웨이브 섹션 아래 `스포너 파괴 돌연변이`에서 사용 여부·확률·증가율·능력치 가중치를 설정합니다. 0.2는 20%입니다.
3. MapLoader가 로드하는 MapConfig의 설정이 실행 시 적용됩니다. 씬 매니저가 없어도 자동 생성합니다.
4. MapLoader 없이 사용하는 씬은 EnemyMutationManager를 직접 붙여 설정할 수 있습니다. 없으면 첫 파괴 시 기본값으로 생성합니다.
5. 플레이 중 스포너 인스펙터에서 누적 효과와 추가 물량 대기 수를 확인합니다.

화면 알림은 첫 돌연변이 발생 시 자동으로 표시됩니다.
플레이 전에 `Tools > 게임 > 돌연변이 매니저 생성 또는 선택`을 실행하면 씬에 매니저를 배치하거나 기존 매니저를 선택합니다. 씬을 저장해야 설정이 유지됩니다.
게임 규칙은 EnemyMutationManager, 알림 표현은 같은 오브젝트의 EnemyMutationHUD(추가 메뉴: 게임/돌연변이 알림 매니저)에서 조절합니다.
기존 매니저가 서로 다른 오브젝트에 있으면 그대로 재사용합니다.

알림 매니저의 설정은 MapConfig가 덮어쓰지 않습니다. 게임 규칙만 스테이지 설정을 따릅니다.

- UI 연결: `누적 효과 텍스트`와 `결과 알림 텍스트`에 TMP 텍스트를 연결합니다. 모두 비어 있고 `자동 UI 생성`을 켜면 기본 UI를 만듭니다.
- 알림 문구: `{효과명}`과 `{증가율}`을 사용합니다. 효과별 이름도 각각 변경할 수 있습니다.
- 누적 효과 문구: `{횟수}`, `{스폰}`, `{공격력}`, `{체력}`, `{이동속도}`를 사용합니다. 증가율에는 %가 포함됩니다.
- 표시: 알림 시간, 글꼴, 글자 크기, 누적 효과 색상, 네 가지 돌연변이별 알림 색상을 설정합니다.
- 연결한 텍스트의 원래 스타일을 쓰려면 `텍스트 스타일 덮어쓰기`를 끕니다. 자동 UI는 매니저의 스타일 설정을 사용합니다.
- 연출: 등장·퇴장 시간과 등장 크기 배율·크기 복원 시간을 설정합니다. 등장/퇴장은 0초로 끄고, 크기 배율은 1로 강조를 없앨 수 있습니다.
- 효과음: 오디오 소스, 알림 클립, 음량을 연결합니다. 소스를 비워두면 전용 2D 소스를 생성합니다.
- 추가 효과: `알림 시작 효과`와 `알림 종료 효과` 이벤트에 파티클 재생/정지 등 원하는 동작을 연결합니다. 시작 이벤트는 대기열에 들어간 순간이 아니라 실제 알림 표시 시 실행됩니다.
- 자동 UI: 우측 상단 기준 위치, 패널 크기, 배경색, 기준 해상도, 표시 순서를 설정합니다.
- 미리보기: 인스펙터에서 결과 문구를 확인하고, 플레이 중 `알림과 효과 미리 재생` 버튼을 누르면 실제 적을 강화하지 않고 표시를 확인합니다. 연결한 효과 이벤트와 소리는 실행됩니다.

알림은 일시정지 중에도 순서대로 재생됩니다. 종료 시 텍스트 색상과 강조 대상의 원래 크기를 복원합니다.
게임 종료·매니저 비활성화·판 초기화 시 알림과 대기열을 정리하고 종료 이벤트를 호출합니다.
플레이 중 인스펙터 변경은 미리보기 용도이며, 플레이 종료 시 유니티가 되돌리므로 영구 설정은 플레이 전에 수정합니다.

## 코드 연결

- `EnemyMutationSettings`: 스테이지별 설정과 후보 종류.
- `EnemyMutationManager`: 추첨, 누적, 기존 적 적용, 판 단위 초기화.
- `EnemyMutationTarget`: 개체별 적용 배율을 기억해 중복 곱연산 방지.
- `EnemyMutationMath`: 추가 물량의 소수점 누적 계산.
- `EnemySpawner`: 파괴 트리거, 주기 추가 물량, 상한 처리.
- `EnemySpawnUtility`, `SelectableEntity`: 신규 생성 및 직접 배치 적의 적용.
- `EntityHealth`: 체력 비율 유지.
- `MapConfig`, `MapLoader`, `StageEditorWindow`: 스테이지 설정과 주입.
- `EnemyMutationHUD`, `EnemySpawnerEditor`: 결과 및 누적 상태 표시.
- `GameResultManager`: 마지막 파괴의 공통 승리 조건.
- `RelicManager`, `RelicPanelUI`: 연속 파괴 보상 대기열 및 종료 시 화면 정리.

## 검증

- 별도 출력 경로에서 런타임·에디터 C# 컴파일 확인.
- 실제 추가 물량 계산 코드로 20% 누적, 40% 누적, 도중 증가율 변경, 0%, 100% 초과를 확인.
- 플레이 확인: 체력 효과만 추첨되도록 설정하고 부상당한 기존 적의 체력 비율 유지 및 신규 적 적용 확인.
- 플레이 확인: 스폰 계열 확률 1, 작은 생존 상한, 유한 웨이브 구성으로 추가 적이 상한을 넘기지 않고 총량을 늘리는지 확인.
- 플레이 확인: 연속 파괴, 활성화 전 파괴, 마지막 파괴, 다음 웨이브 유지, 재시작 초기화, 알림 및 유물 선택 순서 확인.
