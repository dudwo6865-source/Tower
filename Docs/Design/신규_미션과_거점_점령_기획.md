# 신규 미션 분류와 거점 점령 기획

작성일: 2026-10-28

이 문서는 신규 미션의 기획안입니다. 현재 구현된 기능이나 인스펙터 사용 설명이 아닙니다. 기존의 정해진 밤 생존·적 스포너 전부 파괴 미션은 유지하고, 아래 세 가지를 신규 미션의 큰 분류로 둡니다.

## 1. 신규 미션의 큰 분류

### 1번 — 거점 점령

지정된 위치로 병력을 보내 거점을 확보합니다. 기본 개념을 익힌 뒤에는 확보한 전진기지를 일정 시간 방어하는 형태로 확장합니다. 본부와 원정군 사이의 병력 배분, 방어 위치 선정, 현지 건설을 주요 재미로 삼습니다.

처음에는 위치 점령만 소개하고, 이후 방어와 중립 전력 획득을 순서대로 추가합니다. 세부 규칙은 이 문서에서 다룹니다.

### 2번 — 보스 사냥

지정된 보스를 처치하면 승리합니다. 보스의 등장 위치·시점과 공략 특성을 통해 일반 적 소탕과 다른 결전을 만듭니다.

후보는 본부로 진군하는 공성형 보스, 맵 안쪽으로 원정을 가야 하는 둥지형 보스, 수호 구조물을 먼저 파괴하면 약해지는 보스입니다. 첫 도입은 낮에 요격을 준비하고 밤에 맞서는 공성형을 우선 검토합니다. 세부 패턴과 수치는 추후 기획합니다.

### 3번 — 타임어택: 목표물 파괴

제한 시간이나 지정된 밤이 끝나기 전에 특정 목표물을 파괴합니다. 충분히 성장한 뒤 공격할지, 적은 병력으로 일찍 출발할지를 판단하게 합니다.

대표 예시는 소환 의식이 완성되기 전 제단 파괴입니다. 시간 초과 시 즉시 패배할지, 보스 출현 등 추가 위기로 전환할지는 스테이지 성격에 따라 추후 결정합니다. 어느 경우든 시작 전에 시간과 초과 결과를 명확히 알립니다.

## 2. 거점 점령의 도입 방향

### 합의한 핵심 방향

- 점령 미션의 본격적인 형태는 전진기지 확보 후 일정 시간 버티기입니다.
- 확보 후에는 거점 범위 안에 살아 있는 아군 유닛이나 아군 건물이 있으면 거점을 유지합니다.
- 후속 미션에서는 미리 배치한 중립 건물·유닛을 플레이어 소유로 얻는 재미를 추가합니다.

### 이번 문서의 도입안

첫 미션은 특정 위치 한 곳을 점령하는 데 집중합니다. 중립 유닛뿐 아니라 중립 건물의 소유권 이전도 뒤로 미뤄, 처음에는 이동·범위·점령 진행만 배웁니다. 긴 방어 단계는 두 번째 점령 미션부터 소개합니다.

여기서 첫 미션의 짧은 점령 대기와 후속 미션의 방어 시간은 서로 다릅니다. 점령 대기는 위치를 확보하는 과정이고, 방어 시간은 확보 이후 적의 반격을 견디는 과정입니다.

이하의 세부 판정과 예시 수치는 구현 전 조정 가능한 권장안입니다.

## 3. 단계별 세부 미션

### 1단계 — 지정 위치 확보

목표: 플레이어가 표시된 범위로 유닛을 이동시키고, 잠시 머물러 점령을 완료하는 개념을 익힙니다.

1. 시작 시 목표 위치와 점령 범위를 안내합니다.
2. 플레이어가 병력을 준비해 해당 위치로 이동합니다.
3. 범위 안에 아군 유닛이 있고 적이 없으면 점령도가 올라갑니다.
4. 점령을 완료하면 즉시 승리합니다. 별도의 방어 시간은 없습니다.

구성 원칙:

- 거점은 하나만 배치합니다.
- 소유권을 얻는 중립 유닛·건물은 배치하지 않습니다.
- 최초 점령에는 유닛이 필요합니다. 건물만으로 점령을 시작하거나 진행할 수 없습니다.
- 거점 내부는 비워 두거나 약한 수비 병력만 배치합니다. 첫 경험은 이동과 점령에 집중합니다.
- 전용 반격, 제한 시간, 여러 거점 동시 관리, 보스는 넣지 않습니다.
- 본부에서 너무 멀지 않고 접근 경로가 명확한 위치를 사용합니다.
- 기존 밤 공격은 초반 학습을 방해하지 않도록 약하게 조정합니다.
- 본부가 파괴되면 패배합니다. 모든 적이나 스포너를 파괴할 필요는 없습니다.

플레이어 안내 예시: “유닛을 표시된 구역으로 이동시켜 거점을 점령하세요.”

### 2단계 — 전진기지 확보 후 방어

목표: 점령한 위치에 전력을 유지하고 반격을 버티는 법을 익힙니다.

1. 1단계와 같은 방식으로 거점을 점령합니다.
2. 점령 완료 시 방어 타이머를 시작하고 반격을 예고합니다.
3. 범위 안에 아군 유닛 또는 아군 건물을 유지하면서 일정 시간 버팁니다.
4. 방어 시간을 채우면 승리합니다.

구성 원칙:

- 거점은 하나로 유지하고 중립 전력 획득은 아직 넣지 않습니다.
- 플레이어가 직접 데려온 병력과 직접 지은 건물로 방어합니다.
- 거점 주변에 건설 가능한 공간과 적의 진입 경로를 확보합니다. 건설을 승리의 필수 조건으로 강제하지는 않습니다.
- 첫 반격은 한 방향에서 시작하고, 병력이 배치될 여유를 줍니다.
- 거점 반격과 기존 본부 공격을 구분해 설계합니다. 첫 방어 미션에서 양쪽에 강한 공격을 동시에 주지 않습니다.
- 낮과 밤은 계속 흐르며 방어 시간은 둘 다 진행됩니다. 점령 시점 때문에 반격 없이 끝나지 않도록 전용 반격을 구성합니다.

플레이어 안내 예시: “거점 안에 아군 유닛이나 건물을 유지하며 남은 시간 동안 방어하세요.”

### 3단계 — 중립 시설 확보

목표: 점령으로 얻은 시설을 방어에 활용하는 경험을 추가합니다.

- 확보 시 지정된 중립 건물을 플레이어 소유로 전환합니다.
- 첫 사례는 기능이 직관적인 방어 타워를 권장합니다.
- 획득한 건물도 거점 유지 조건에 포함합니다.
- 중립 유닛은 아직 제외해 시설 획득의 의미를 먼저 보여줍니다.
- 후속 스테이지에서는 생산 건물을 얻어 현지에서 병력을 충원하는 구성으로 확장합니다.

### 4단계 — 중립 부대 확보와 확장

목표: 점령으로 얻은 병력을 원정·거점 방어·본부 지원 중 어디에 사용할지 선택하게 합니다.

- 지정된 중립 유닛을 최초 확보 시 플레이어 소유로 전환합니다.
- 획득한 유닛은 거점 밖으로 이동하고 일반 플레이어 명령을 받을 수 있습니다.
- 유닛을 전부 이동시키고 거점에 아군 건물도 남지 않으면 거점 유지가 중단됩니다.
- 이후 순차 점령, 여러 후보 중 일부 점령, 복수 거점 방어로 확장합니다. 첫 도입부터 여러 거점 동시 방어를 요구하지 않습니다.

## 4. 점령과 방어의 공통 판정 권장안

### 최초 점령과 재점령

- 살아 있는 플레이어 소유 유닛이 범위 안에 한 명 이상 있고 적 유닛·건물이 없으면 진행합니다.
- 적이 진입하면 점령 진행을 일시 정지합니다. 적을 제거하면 이어서 진행합니다.
- 아군 유닛이 모두 나가거나 사망하면 완료 전 점령 진행도는 초기화합니다.
- 유닛 수가 많아져도 점령 속도는 같게 유지합니다.
- 미점령 상태에서 아군 건물만 남아 있으면 점령은 진행하지 않습니다.

### 확보 후 방어

- 범위 안에 살아 있는 아군 유닛 또는 완성된 아군 건물이 하나 이상 있으면 방어 시간이 흐릅니다.
- 적이 범위에 들어와도 아군이 남아 있으면 방어 시간은 계속 흐릅니다. 거점 내부 교전도 방어로 인정합니다.
- 건설 미리보기, 건설 중인 건물, 시체, 중립 오브젝트는 유지 조건에 포함하지 않습니다.
- 유닛은 지면상 위치, 건물은 배치 중심이 점령 범위 안에 있는지로 판정하는 것을 기본안으로 합니다. 건물 외형의 일부만 걸친 상태는 인정하지 않습니다.
- 게임 일시 정지 중에는 점령·방어·유예 시간이 모두 멈춥니다.

### 이탈과 거점 상실

- 아군 유닛과 완성된 아군 건물이 모두 없어지면 방어 시간이 멈추고 탈환 유예 시간이 시작됩니다.
- 유예 안에 유지 조건을 회복하면 누적 방어 시간부터 이어서 진행합니다.
- 유예가 끝나면 거점을 상실하고 방어 진행도는 초기화합니다. 미션은 즉시 패배하지 않으며 다시 점령할 수 있습니다.
- 재점령에는 다시 아군 유닛이 필요합니다.
- 재점령으로 반격 부대가 무한히 중첩되거나 보상이 반복 지급되지 않게 합니다. 반격 재개·재예약의 상세 방식은 구현 전에 정합니다.
- 본부 파괴와 승리 조건이 동시에 충족되면 본부 파괴에 따른 패배를 우선합니다.

### 중립 전력의 소유권 — 후속 단계에만 적용

- 소유권 전환 대상은 거점마다 미리 지정합니다. 범위 안의 모든 중립 대상을 자동 획득하지 않습니다.
- 최초 점령 완료 시 살아 있는 지정 대상만 한 번 전환합니다. 이미 파괴된 대상은 부활시키지 않습니다.
- 거점을 상실해도 획득한 건물·유닛은 플레이어 소유를 유지합니다.
- 재점령으로 복제·재지급·체력 회복이 발생하지 않습니다.
- 소유권을 얻은 대상과 현재 범위 안에서 거점을 유지하는 대상은 별도로 판단합니다.

## 5. 초기 조정값 제안

아래 값은 테스트 시작점이며 확정 밸런스가 아닙니다. 구현 시에는 스테이지별로 에디터에서 조절할 수 있게 합니다.

- 최초 점령 시간: 5초.
- 1단계 방어 시간: 사용하지 않음. 점령 완료 즉시 승리.
- 2단계 방어 시간: 60초.
- 거점 이탈 유예: 10초.
- 2단계 첫 반격: 확보 10초 후 도착을 목표로 배치와 출격 시점을 조정.
- 거점 크기: 기본 부대 하나와 방어 건물 1~2개를 배치할 수 있는 공간부터 테스트.

거점 위치·범위, 점령 시간, 방어 단계 사용 여부, 방어 시간, 이탈 유예, 반격 구성, 소유권 전환 대상을 스테이지별 기획 항목으로 둡니다. 구체적인 컴포넌트와 인스펙터 이름은 구현 때 정합니다.

## 6. 플레이어에게 보여줄 정보

- 목표 위치와 실제 판정에 일치하는 점령 범위.
- 현재 단계: 미점령 / 점령 중 / 적 때문에 점령 중단 / 방어 중 / 이탈 유예 / 상실 / 완료.
- 점령 진행도와 방어 남은 시간. 첫 미션에서는 사용하지 않는 방어 타이머를 표시하지 않습니다.
- 아군 부재로 시간이 멈춘 이유와 거점 상실까지 남은 유예 시간.
- 반격이 시작되기 전 진입 방향과 예고.
- 중립 전력 획득 단계에서는 획득 대상과 소유권 전환 결과.

목표 위치는 시작부터 안내하되 주변 적의 시야를 자동으로 공개하지 않습니다. UI 외형과 배치는 유니티 에디터에서 디자인하고 참조를 연결하는 기존 원칙을 따릅니다.

## 7. 플레이 테스트에서 확인할 사항

- 첫 미션에서 설명을 길게 읽지 않아도 유닛을 어디로 보내야 할지 이해하는가?
- 점령 완료 전 대기와 확보 후 방어의 차이가 분명한가?
- 아군이 사라졌을 때 타이머가 멈추는 이유를 바로 알 수 있는가?
- 적이 진입했을 때 최초 점령은 멈추지만 확보 후 방어는 계속된다는 차이가 전달되는가?
- 부대의 자동 추격으로 범위를 벗어나 억울하게 거점을 잃지는 않는가?
- 범위 밖 건물이나 미완성 건물이 유지 대상으로 잘못 인식되지는 않는가?
- 적이 거점 수비 전력과 실제로 교전하는가? 외곽의 유닛 하나만 숨겨 쉽게 통과하지는 않는가?
- 본부와 거점의 동시 방어가 학습 단계에 비해 과하지 않은가?
- 재점령으로 반격이 과도하게 쌓이거나 중립 전력이 반복 지급되지는 않는가?

## 8. 다음 기획에서 결정할 항목

- 실제 맵과 기본 부대 크기에 맞춘 거점 크기, 방어 시간, 반격 병력.
- 거점 상실 후 기존 반격 부대의 행동과 재점령 시 추가 반격 방식.
- 중립 상태의 피격 가능 여부와 획득 건물의 생산·업그레이드 이용 범위.
- 보스 미션의 첫 보스 유형과 타임어택의 시간 초과 처리.

우선 제작할 범위는 1단계의 단일 위치 점령입니다. 그 경험을 확인한 뒤 같은 규칙 위에 방어 단계, 중립 건물, 중립 유닛을 차례로 추가합니다.
