# 1Stage 기반 추가 스테이지

1. Unity에서 플레이 모드를 종료하고 `Assets > Refresh`를 실행합니다.
2. `Tools > 맵 > 1Stage 기반 추가 스테이지 5개 생성`을 실행합니다.
3. `Assets/Data/Stage/Expansion`에 `2Stage`부터 `6Stage`까지 데이터, 맵 프리팹, 구워진 NavMesh가 생성됩니다.
4. 로비의 `MissionSelectionUI` 미션 목록에 생성된 스테이지 데이터를 순서대로 등록합니다.

원본 `1Stage`의 절벽/언덕 타일 세트, 본부/스포너 건물 설정, 경제, 낮밤, 웨이브, 초기 적, 승리 조건, 보상을 복사합니다. 원본 에셋은 수정하지 않습니다. 생성 결과가 이미 있으면 덮어쓰지 않습니다.

맵 크기는 외곽 절벽 한 칸을 포함한 격자 경계의 **면적 기준**입니다. 원본 27×16칸 대비 약 1.53 / 1.65 / 1.78 / 1.92 / 2.00배이고 스포너는 각각 5 / 6 / 7 / 8 / 9개입니다. 서로 다른 중앙 절벽과 남북 우회로를 가지며 후반 맵에는 본부와 가까운 측면 스포너도 추가됩니다.

생성 중 지형 연결과 각 스포너에서 본부까지의 NavMesh 경로를 검사합니다. 실패하면 해당 실행에서 생성한 폴더를 정리하고 콘솔에 원인을 남깁니다. 성공하면 폴더 안 `생성결과.txt`에서 결과를 확인할 수 있습니다. 실제 전투 난이도는 플레이 후 조정해야 합니다.

프리팹을 열고 기존 절벽 맵 에디터로 추가 편집할 수 있습니다. 건물 배치는 지형 재생성으로 지워지지 않도록 별도 `건물 배치` 오브젝트에 저장합니다. 지형을 수정한 뒤에는 NavMesh도 다시 구워주세요.

전투 씬의 MapLoader가 씬에 배치된 기존 맵을 우선 사용하도록 설정되어 있다면, 선택한 스테이지의 프리팹으로 교체하는 설정을 사용해야 합니다.
