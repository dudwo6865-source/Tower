# 스테이지 시작 연출 설정

## 전투 씬의 UI 연결

UI는 에디터에서 직접 만듭니다. 스크립트는 패널과 텍스트를 생성하거나 디자인 값을 변경하지 않고, 연결된 CanvasGroup의 알파와 입력 차단만 제어합니다.

1. `Battle` 씬의 Canvas 아래에 `시작 연출` 오브젝트를 만들고 `StageIntroController`를 붙입니다. 맵 프리팹이 아니라 전투 씬에 두어 맵 로딩보다 먼저 실행되게 합니다.
2. 자식으로 `암전 패널`과 `안내 문구`를 **서로 별개의 형제 오브젝트**로 만듭니다. 두 오브젝트 모두 활성화해 둡니다.
3. `암전 패널`에는 화면 전체를 덮는 검은 Image와 CanvasGroup을 붙입니다. Image의 Raycast Target은 켭니다. CanvasGroup Alpha는 1로 둡니다.
4. `안내 문구`에는 CanvasGroup을 붙이고 스테이지 이름·목표·로어 안내용 TMP 텍스트를 배치합니다. 이 그룹은 암전 패널보다 뒤의 형제 순서에 두어 위에 표시되게 합니다. CanvasGroup Alpha는 0으로 둡니다.
5. StageIntroController의 `암전 패널`, `안내 문구 그룹`, 세 텍스트 항목에 각각 연결합니다. 폰트·크기·색·정렬·위치는 원하는 대로 디자인합니다.
6. 여러 Canvas가 있으면 시작 연출 Canvas의 정렬 순서를 HUD보다 높게 설정합니다. 화면 전체 배경과 텍스트가 보이는지 확인합니다.

암전 패널과 안내 문구 그룹은 필수입니다. 연결이 빠졌거나 서로 부모·자식이면 경고를 남기고 연출을 생략합니다. 두 그룹을 공통 부모 아래에 두는 것은 가능합니다. 다른 자동 페이드 컴포넌트가 같은 CanvasGroup의 알파를 수정하지 않게 하세요.

## 기본 진행

- 로딩: 게임 시간·공격·플레이어 입력을 멈추고 맵, 시작 건물, 초기 적과 보스 배치를 기다립니다. 시작 건물의 생성 지연은 이때만 실제 시간으로 진행하며 건설 애니메이션은 생략합니다.
- 공개: 본부로 카메라를 맞추고 1초 동안 암전을 걷습니다. 스테이지 이름과 목표가 나타납니다.
- 로어: 화면 공개가 끝나면 BossNest의 로어가 재생됩니다. 1초 동안 안내를 유지합니다.
- 시작: 0.3초 동안 문구를 지운 다음 시간과 입력을 복구합니다. 긴 로어는 끝까지 이어집니다.

`화면 공개 시간`, `공개 후 안내 유지 시간`, `문구 사라짐 시간`은 실제 시간 기준이며 인스펙터에서 조절합니다. 로딩 대기 제한은 기본 30초입니다. 초기 배치가 잘못돼 제한을 넘으면 경고를 남기고 암전과 입력 잠금을 해제하며, 공개 신호를 보내지 않아 로어도 생략합니다.

스테이지 이름은 MapLoader의 MapConfig에서 읽습니다. 일반 목표·보스 목표·로어 안내 문구는 StageIntroController에서 변경합니다. 보스 조건이 없는 스테이지에도 같은 시작 연출을 사용할 수 있습니다.

## 보스 로어

스테이지의 BossNest에서 `등장 사운드`에 클립을 연결합니다. `재생 지연 시간(초)`을 **0**으로 두면 화면 공개 직후 재생합니다. 양수이면 화면 공개 이후 그만큼 실제 시간을 더 기다립니다. 출력 믹서와 볼륨은 기존 설정을 사용합니다.

시작 연출이 없는 씬에서는 기존처럼 보스 생성 후 로어를 재생합니다. 보스를 UnitCombatAI로 바꿔 직접 배치한 테스트 유닛은 이 스테이지 등장 로어의 대상이 아닙니다.

## 플레이 확인

- 본부 생성 지연을 설정해도 암전 상태에서 배치가 끝나고 본부 화면으로 공개되는지 확인합니다.
- 공개 이전에는 로어가 들리지 않고 키보드·마우스로 선택, 명령, 건설, 카메라 이동을 할 수 없는지 확인합니다.
- 문구가 사라진 다음 낮밤 시간과 조작이 시작되고, 긴 로어는 중간에 끊기지 않는지 확인합니다.
- 연출 도중 컴포넌트를 끄거나 씬을 나갈 때 암전·입력·시간이 잠긴 채 남지 않는지 확인합니다.
- UI 연결 누락 또는 배치 오류 시 콘솔 안내와 함께 연출이 안전하게 해제되는지 확인합니다.
