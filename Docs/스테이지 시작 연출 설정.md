# 스테이지 시작 연출 설정

안내 문구 없이 **로딩 중 암전 → 본부 화면 공개 → 로어 재생과 조작 시작** 순서로 진행합니다. UI는 에디터에서 직접 만들고, 코드는 연결된 CanvasGroup의 알파와 입력 차단만 제어합니다.

## 전투 씬에서 연결

1. `Battle` 씬의 Canvas 아래에 `StageIntro` 오브젝트를 만들고 `StageIntroController`를 붙입니다. 맵 프리팹이 아니라 전투 씬에 둡니다.
2. 화면 전체를 덮는 검은 Image와 CanvasGroup을 만들고 `암전 패널`에 연결합니다. Image의 Raycast Target은 켜고 오브젝트는 활성 상태로 둡니다.
3. 검은 Image가 StageIntro의 자식이면 StageIntro 자체의 CanvasGroup을 연결해도 됩니다. 이 경우 자식은 암전용 요소만 두세요.
4. `화면 공개 시간(초)`으로 암전이 걷히는 시간을 조절합니다. 기본값은 1초입니다.
5. 시작 연출 Canvas는 HUD보다 위에 보이도록 정렬 순서를 설정합니다. 위치·크기·색은 에디터에서 직접 설정합니다.

텍스트나 안내 문구 그룹은 필요하지 않습니다. 이전 버전에서 연결한 스테이지 이름·목표·로어 안내 TMP 텍스트는 자동으로 숨깁니다. 해당 텍스트와 빈 안내 문구 오브젝트는 에디터에서 삭제해도 됩니다.

## 보스 로어

스테이지의 `BossNest → 등장 사운드`에 로어 클립을 연결합니다. `재생 지연 시간(초)`을 **0**으로 두면 화면 공개 완료 직후 재생됩니다. 양수이면 공개 이후 실제 시간으로 더 기다립니다. 로어 길이와 관계없이 공개가 끝나면 조작을 시작합니다.

시작 연출이 없는 씬에서는 기존처럼 보스 생성 후 로어를 재생합니다.

## 로딩과 취소

연출 중에는 게임 시간·공격·플레이어 입력을 멈추고 맵, 시작 건물, 초기 적과 보스 배치를 기다립니다. 시작 건물의 생성 지연은 이때만 실제 시간으로 진행하고, 건설 연출은 생략해 완성 상태로 보여줍니다.

암전 패널이 연결되지 않으면 경고 후 연출을 생략합니다. 로딩 대기 제한은 기본 30초이며, 초과 시 경고와 함께 암전·입력·시간 잠금을 해제합니다. 공개 전에 취소되면 로어도 생략합니다.

## 플레이 확인

- 로딩과 화면 공개 중 안내 문구가 나타나지 않는지 확인합니다.
- 본부 생성 지연이 있어도 배치 완료 후 본부 화면을 공개하는지 확인합니다.
- 공개 전에는 로어와 조작이 시작되지 않고, 공개 직후 둘 다 시작되는지 확인합니다.
- 연출 도중 컴포넌트를 끄거나 씬을 나갈 때 입력·시간 잠금이 남지 않는지 확인합니다.
